**Caveats.** Times are wall-clock seconds of pure-Python code on one machine (Windows-11-10.0.26200-SP0, Python 3.12.1) and are indicative only; model evaluations (read from each model's evaluation counter) are machine-independent and are the cost measure to compare. Seeds per category: reliability 2, sensitivity 2, propagation 5, calibration 2, inverse 2, assimilation 2; deterministic methods (FORM, SORM, bounds, closed forms) run once. Quick mode uses small budgets and few seeds: its numbers show behaviour, not converged accuracy. Problems run in full mode only (omitted here): `linear-100d`, `lorenz96-twin`.

**Columns.** *Rel. error*: median over seeds of |estimate - reference| / |reference|. *Median abs z*: |estimate - reference| / (the method's own reported standard error), pooled over seeds; about 0.67 is ideal, values well above 2 mean the method under-reports its error (a reported SE below 1e-06 x |reference| is floored there, the level of solver tolerances). *Coverage*: how often the reference lay inside the method's own interval (estimate +/- 1.96 SE, a bootstrap 95 % interval, or a 90 % credible interval for calibration). Methods marked as approximations (FORM, SORM, PCE, Laplace, ADVI) report no error bar, so only their error is shown. Failures are caught and listed under each table, never dropped.

**Profiles** (ADR-0077). Each category ends with performance profiles (Dolan and Moré 2002) and data profiles (Moré and Wild 2009) over its problem instances (a problem and quantity group). A method *solves* an instance when its median error meets the *accurate* threshold of 'What the numbers say'; its cost t is then its mean model evaluations, and its ratio is r = t / (smallest t of any method on that instance). An inaccurate, failed, skipped, or inapplicable method has r = infinity. *Accurate on*: instances solved at any cost. *rho(tau)*: instances solved with r <= tau; *Wins rho(1)* counts a tie for every tied method. *tau for 50 %*: smallest ratio at which half the instances are solved. *Area*: mean of rho over log2 tau in [0, log2 tau_max], 1 when a method is the cheapest accurate one everywhere. *d(kappa)*: instances solved within kappa (n + 1) evaluations, n the input dimension; *kappa for 50 %*: that budget for half of them. With quick-mode budgets and a handful of instances per category the profiles are coarse.
