# Measure-Theoretic Probability on Finite Spaces

`probstat.probability.FiniteSampleSpace` treats every subset of a finite
sample space as an event. That convention hides the object that measure
theory makes explicit: the sigma-algebra `F`, the collection of events an
observer can actually decide. Conditioning, sufficiency, filtrations, and
densities are all statements about sigma-algebras, so the measure bridge
`probstat.probability.measure` makes `F` a first-class value while keeping
every computation finite and, for rational inputs, exact.

| Concept | Object | Equation |
|---|---|---|
| sigma-algebra generated by sets | `FiniteMeasurableSpace` | [EQ-MEAS-001] |
| measure, additivity | `FiniteMeasure` | [EQ-MEAS-002] |
| measurable map, image measure | `is_measurable_map`, `pushforward` | [EQ-MEAS-003] |
| Lebesgue integral | `simple_integral`, `integrate` | [EQ-MEAS-004] |
| product measure, Fubini-Tonelli | `product`, `fubini_check` | [EQ-MEAS-005] |
| Radon-Nikodym derivative | `radon_nikodym_derivative`, `with_density` | [EQ-MEAS-006], [EQ-MEAS-007] |
| conditional expectation | `conditional_expectation` | [EQ-MEAS-008] |
| total variation | `total_variation_distance` | [EQ-MEAS-009] |
| completeness | `check_completeness` | [EQ-MEAS-010] |

Every block below is executed by `tests/test_measure_theory.py`, and the
text block after it is the exact output. The general theory is in
Billingsley [REF-BILLINGSLEY-1995] and Durrett [REF-DURRETT-2019]; section
locators are given with each topic.

## 1. Sigma-algebras and atoms

A sigma-algebra on `Omega` contains `Omega` and is closed under complements
and countable unions [REF-BILLINGSLEY-1995, Section 2],
[REF-DURRETT-2019, Section 1.1]. On a finite set the sigma-algebra
generated by a collection `G` of subsets has a simple description: two
outcomes are indistinguishable when every generator contains both or
neither, the classes of indistinguishable outcomes are the *atoms*, and the
events are exactly the unions of atoms. With `k` atoms there are `2^k`
events ([EQ-MEAS-001]).

For a die, knowing only whether the face is even and whether it is at most
three gives four atoms and sixteen events:

```python
from fractions import Fraction

from probstat.probability import (
    FiniteMeasurableSpace,
    FiniteMeasure,
    check_completeness,
    is_sigma_algebra,
)

faces = range(1, 7)
info = FiniteMeasurableSpace(faces, [{2, 4, 6}, {1, 2, 3}])
print([sorted(atom) for atom in info.atoms])
print(info.event_count, len(list(info.events())))
print(info.is_measurable({1, 3}), info.is_measurable({1, 2}))
print(is_sigma_algebra(faces, info.events()))
print(is_sigma_algebra(faces, [set(), {1}, set(faces)]))
```

```text
[[1, 3], [2], [4, 6], [5]]
16 16
True False
True
False
```

`{1, 2}` is not an event: it splits the atom `{1, 3}`, so an observer with
this information cannot decide it. The last family fails because the
complement of `{1}` is missing.

A sigma-algebra `G` is contained in `F` exactly when every atom of `G` is a
union of atoms of `F`; the finer partition carries more information.

```python
parity = FiniteMeasurableSpace.generated_by_map(faces, lambda face: face % 2)
print([sorted(atom) for atom in parity.atoms])
print(parity.is_sub_sigma_algebra_of(info), info.is_sub_sigma_algebra_of(parity))
```

```text
[[1, 3, 5], [2, 4, 6]]
True False
```

## 2. Measurable maps and image measures

A map `f : (Omega, F) -> (Omega', F')` is measurable when `f^-1(B)` is in
`F` for every `B` in `F'` [REF-BILLINGSLEY-1995, Section 13],
[REF-DURRETT-2019, Section 1.3]. Checking the atoms of `F'` is enough. A real
function with a finite range is measurable exactly when it is constant on
every atom, so the face value itself is not a random variable on `info`,
while the indicator of an even face is ([EQ-MEAS-003]).

```python
fair = FiniteMeasure.from_point_masses({face: Fraction(1, 6) for face in faces})
coarse = fair.restrict(info)
print({tuple(sorted(a)): str(m) for a, m in coarse.atom_masses.items()})
print(info.is_measurable_function(lambda face: face))
print(info.is_measurable_function(lambda face: face % 2))

labels = FiniteMeasurableSpace(["odd", "even"])
to_label = {face: "even" if face % 2 == 0 else "odd" for face in faces}
law = coarse.pushforward(to_label, labels)
print({sorted(a)[0]: str(m) for a, m in law.atom_masses.items()})
try:
    coarse.pushforward(lambda face: "low" if face <= 2 else "high",
                       FiniteMeasurableSpace(["low", "high"]))
except ValueError as error:
    print("rejected:", error)
```

```text
{(1, 3): '1/3', (2,): '1/6', (4, 6): '1/3', (5,): '1/6'}
False
True
{'odd': '1/2', 'even': '1/2'}
rejected: mapping is not measurable into the target space
```

The image measure `mu o f^-1` is the law of the random element `f`
[REF-DURRETT-2019, Section 1.2]. The map "face at most two" splits the atom
`{1, 3}`, so its law is not defined on `info`.

## 3. The Lebesgue integral

The integral of a simple function `sum_i c_i 1_(A_i)` is
`sum_i c_i mu(A_i)`; the integral of a non-negative measurable function is
the supremum over simple functions below it, and linearity extends it to
integrable functions [REF-BILLINGSLEY-1995, Sections 15-16],
[REF-DURRETT-2019, Sections 1.4-1.6]. On a finite space every measurable
function is already simple on the atom partition, so the integral equals a
finite sum over atoms ([EQ-MEAS-004]). Different representations of the
same simple function give the same value:

```python
value = {face: face for face in faces}
print(fair.integrate(value))
print(fair.simple_integral([(1, faces), (1, {2, 3, 4, 5, 6}), (1, {3, 4, 5, 6}),
                            (1, {4, 5, 6}), (1, {5, 6}), (1, {6})]))
print(fair.simple_integral([(face, {face}) for face in faces]))
print(fair.integrate_over(value, {2, 4, 6}))
```

```text
7/2
7/2
7/2
2
```

The first representation is the layer-cake form `X = sum_k 1_(X >= k)`.

## 4. Product measures and Fubini-Tonelli

The product sigma-algebra is generated by measurable rectangles `A x B`,
and the product measure is the unique measure with
`(mu x nu)(A x B) = mu(A) nu(B)`. Fubini-Tonelli states that integrating
first over one coordinate and then over the other gives the integral against
the product measure [REF-BILLINGSLEY-1995, Section 18],
[REF-DURRETT-2019, Section 1.7]. Every product-measurable function on a
finite product is integrable, so the three values coincide exactly
([EQ-MEAS-005]):

```python
coin = FiniteMeasure.from_point_masses({"H": Fraction(1, 3), "T": Fraction(2, 3)})
joint = fair.product(coin)
print(len(joint.space.atoms), str(joint.total_mass))
check = fair.fubini_check(lambda pair: pair[0] ** 2 * (3 if pair[1] == "H" else -1), coin)
print(check.product_integral, check.outer_first, check.outer_second, check.agree)
```

```text
12 1
91/18 91/18 91/18 True
```

## 5. Radon-Nikodym derivatives

`nu` is absolutely continuous with respect to `mu` (`nu << mu`) when every
`mu`-null set is `nu`-null. The Radon-Nikodym theorem then gives a
non-negative density `d nu / d mu` with `nu(A) = integral_A (d nu / d mu)
dmu`, unique `mu`-almost everywhere [REF-BILLINGSLEY-1995, Section 32]. On a
finite space the density is the atom-wise ratio `nu(a) / mu(a)`
([EQ-MEAS-006]); for three measures `lambda << nu << mu` the densities
multiply ([EQ-MEAS-007]).

```python
loaded = FiniteMeasure.from_point_masses(
    {1: Fraction(1, 10), 2: Fraction(1, 10), 3: Fraction(1, 10),
     4: Fraction(1, 10), 5: Fraction(1, 10), 6: Fraction(1, 2)})
density = loaded.radon_nikodym_derivative(fair)
print([str(density[face]) for face in faces])
print(fair.with_density(density).atom_masses == loaded.atom_masses)

six_only = FiniteMeasure.from_point_masses({face: int(face == 6) for face in faces})
outer = six_only.radon_nikodym_derivative(loaded)
inner = loaded.radon_nikodym_derivative(fair)
direct = six_only.radon_nikodym_derivative(fair)
print(all(outer[f] * inner[f] == direct[f] for f in faces))
try:
    fair.radon_nikodym_derivative(six_only)
except ValueError as error:
    print("rejected:", error)
pmf = loaded.radon_nikodym_derivative(FiniteMeasure.counting(faces))
print(str(pmf[6]))
```

```text
['3/5', '3/5', '3/5', '3/5', '3/5', '3']
True
True
rejected: the measure is not absolutely continuous w.r.t. reference
1/2
```

The fair die charges faces that `six_only` makes impossible, so it has no
density with respect to it. A probability mass function is the density
with respect to counting measure, and a likelihood ratio is a
Radon-Nikodym derivative between two models.

## 6. Conditional expectation

For a sub-sigma-algebra `G`, `E[X | G]` is the `G`-measurable function with
`integral_A E[X | G] dmu = integral_A X dmu` for every `A` in `G`; it exists
by the Radon-Nikodym theorem and is unique almost everywhere
[REF-BILLINGSLEY-1995, Section 34], [REF-DURRETT-2019, Section 4.1]. On a
finite space it is the average of `X` over each atom of `G` with positive
mass ([EQ-MEAS-008]). The tower property `E[E[X | G] | H] = E[X | H]` for
`H` inside `G` and the rule `E[Z X | G] = Z E[X | G]` for `G`-measurable `Z`
hold exactly:

```python
given_parity = fair.conditional_expectation(value, parity)
print([str(given_parity[face]) for face in faces])
nothing = FiniteMeasurableSpace.trivial(faces)
print(fair.verify_tower_property(value, info, parity))
print(fair.verify_tower_property(value, parity, nothing))
print(fair.verify_taking_out_what_is_known(value, lambda face: 1 + face % 2, parity))
print(str(loaded.conditional_expectation(value, parity)[2]))
```

```text
['3', '4', '3', '4', '3', '4']
True
True
True
36/7
```

Conditioning depends on the measure: under the loaded die an even face has
conditional mean `36/7`, under the fair die `4`.

## 7. Total variation

The total-variation distance `sup_A |P(A) - Q(A)|` equals half the `L1`
distance between atom masses, and the supremum is attained at the union of
atoms where `P` exceeds `Q` [REF-TSYBAKOV-2009, Chapter 2]
([EQ-MEAS-009]). An exhaustive search over all 64 events confirms it:

```python
tv = loaded.total_variation_distance(fair)
search = max(abs(loaded.measure_of(e) - fair.measure_of(e)) for e in fair.space.events())
print(tv, search)
```

```text
1/3 1/3
```

## 8. Completeness of a statistic

A statistic `T` is *complete* for a family `{P_theta}` when
`E_theta[g(T)] = 0` for every `theta` implies `g(T) = 0` almost surely
[REF-LEHMANN-CASELLA-1998, Section 1.6], [REF-CASELLA-BERGER-2002,
Section 6.2.4]. Completeness is what makes an unbiased function of a
sufficient statistic unique (the Lehmann-Scheffe argument). For finitely
many parameters and statistic values it is a rank condition on the matrix
`A[theta, t] = P_theta(T = t)` ([EQ-MEAS-010]), so it can be computed
exactly.

For three Bernoulli trials the count `T = X_1 + X_2 + X_3` takes four
values. It is complete when the family contains four distinct `p`, and not
complete with three. The full sample `(X_1, X_2, X_3)` is never complete:
`X_2 - X_3` is a non-zero unbiased estimator of zero.

```python
from itertools import product

trials = list(product((0, 1), repeat=3))


def bernoulli_family(probabilities):
    return {p: {s: p ** sum(s) * (1 - p) ** (3 - sum(s)) for s in trials}
            for p in probabilities}


four = bernoulli_family([Fraction(k, 5) for k in range(1, 5)])
three = bernoulli_family([Fraction(k, 5) for k in range(1, 4)])
for name, family, statistic in (("count, 4 values of p", four, sum),
                                ("count, 3 values of p", three, sum),
                                ("full sample", four, lambda s: s)):
    result = check_completeness(family, statistic)
    print(f"{name}: rank {result.rank} of {len(result.statistic_values)}, "
          f"complete {result.is_complete}")
witness = check_completeness(four, lambda s: s).witness
print({s: str(g) for s, g in witness.items() if g != 0})
```

```text
count, 4 values of p: rank 4 of 4, complete True
count, 3 values of p: rank 3 of 4, complete False
full sample: rank 4 of 8, complete False
{(0, 0, 1): '-1', (0, 1, 0): '1'}
```

The verdict depends on the parameter set: the binomial count is complete
for `p` ranging over `(0, 1)` but not over three points, because a cubic
in `p` can vanish at three points without vanishing identically.

## Limitations

- Only finite outcome sets are represented. Countable and continuous
  spaces, Lebesgue measure on the line, and limit theorems for integrals
  (monotone and dominated convergence) are described, not constructed.
- `events()` enumerates `2^k` sets and is meant for small examples.
- With `float` inputs, comparisons and the completeness rank use an
  explicit tolerance; exact answers require `int` or `Fraction` inputs.
- Spaces are compared by their outcome sets and atoms; this differs from the
  identity-based ownership of `FiniteSampleSpace` (ADR-0002), because a
  sub-sigma-algebra is by definition a second structure on the same set.
