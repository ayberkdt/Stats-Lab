### EQ-SYS-ADAPT-001 — Modular decomposition of a coherent system

`phi(x) = psi(chi_1(x^{A_1}), ..., chi_m(x^{A_m}))` for disjoint modules
`A_1, ..., A_m`; with independent modules,
`R_sys = h_psi(R_{chi_1}, ..., R_{chi_m})`, where each module reliability
(or availability) is computed by its own exact model (BDD structure or
continuous-time Markov chain).

- Domain: modules share no component; module states mutually independent
  (no shared repair crews, loads, or common-cause groups across modules).
- Meaning: a subsystem can be replaced by one block whose reliability is the
  subsystem's exact reliability; the composed result is then exact.
- Code: `systems.MarkovComponent`, `systems.SubsystemComponent`.
- Source: [REF-BARLOW-PROSCHAN-1975], [REF-RAUSAND-HOYLAND-2004].

### EQ-SYS-BDD-001 — Shannon expansion and BDD probability

`f = (not x_v and f|_{x_v=0}) or (x_v and f|_{x_v=1})`;
`P(f_n = 1) = (1 - p_v) P(f_low = 1) + p_v P(f_high = 1)` and the same
recursion for `P(f_n = 0)`, with `P(TRUE = 1) = 1`, `P(FALSE = 1) = 0`.

- Domain: reduced ordered BDD; independent variables with `P(x_v = 1) = p_v`.
- Meaning: exact probability of a Boolean (structure) function; each value is
  a convex combination of child values, so neither `R` nor `Q = 1 - R`
  suffers cancellation when both `p_v` and `1 - p_v` are supplied.
- Code: `systems.BDD.probability`, `systems.SystemStructure.reliability`,

### EQ-SYS-MOM-001 — Exact epistemic variance of the reliability polynomial

### EQ-SYS-MOM-002 — Moments with shared epistemic parameters

For a block `B` of components that share one uncertain value `q_B`,
node values inside the block are polynomials
`sum c_jk q_B^j (1 - q_B)^k` (`c_jk >= 0`); children in deeper blocks enter
as their expectations, and `E_B[q^j (1 - q)^k]` integrates a block out.
`E[R^2]` uses the same scheme on node pairs; `Var[R] = E[g^2] - E[g]^2` for
`g` the function or its complement with the smaller mean. Beta law:
`E[q^j (1 - q)^k] = prod_{i<j} (a + i) prod_{i<k} (b + i) /
prod_{i<j+k} (a + b + i)`; raw moments: `sum_i C(k, i) (-1)^i E[q^(j+i)]`.

- Domain: blocks on consecutive BDD levels (the structure reorders
  variables to make them so); blocks independent; raw moments up to twice
  the block size.
- Meaning: exact mean and variance under state-of-knowledge correlation of
  identical components.
- Code: `systems.BDD.grouped_moments`,
  `systems.SystemStructure.reliability_moments`.
- Source: [REF-APOSTOLAKIS-KAPLAN-1981].
  - [REF-APOSTOLAKIS-KAPLAN-1981](../references.md#ref-apostolakis-kaplan-1981): George Apostolakis and Stanley Kaplan. "Pitfalls in Risk Calculations." *Reliability Engineering* 2(2), 135-145, 1981.

### EQ-SYS-SIFT-001 — Adjacent variable swap and sifting

With `x` directly above `y`,
`f = not x (not y f00 + y f01) + x (not y f10 + y f11)
= not y (not x f00 + x f10) + y (not x f01 + x f11)`,
so a node testing `x` with a child testing `y` is relabelled `y` with
children `ite(x, f10, f00)` and `ite(x, f11, f01)`; a node whose children
do not test `y` keeps its label and moves below `y`. Sifting moves each
variable (largest levels first) through every position by such swaps and
leaves it where the shared size is smallest.

- Domain: reduced ordered BDDs; reference-counted nodes so that the live
  size is exact after every swap.
- Meaning: the swap changes two levels only and preserves every
  represented function, hence every probability; the chosen position is
  the best one seen, so the size never increases. The interleaved function
  `x1 x2 + ... + x(2n-1) x(2n)` drops from `2^(n+1) - 2` to `2n` nodes.
- Code: `systems.BDD.sift`, `systems.BDD.reorder`, `systems.ReorderResult`.
- Source: [REF-RUDELL-1993], [REF-BRYANT-1986].
  - [REF-RUDELL-1993](../references.md#ref-rudell-1993): Richard Rudell. "Dynamic Variable Ordering for Ordered Binary Decision Diagrams." In *Proceedings of the 1993 IEEE/ACM International Conference on Computer-Aided Design (ICCAD-93)*, Santa Clara, CA, 42-47, 1993. doi:10.1109/ICCAD.1993.580029.
  - [REF-BRYANT-1986](../references.md#ref-bryant-1986): Randal E. Bryant. "Graph-Based Algorithms for Boolean Function Manipulation." *IEEE Transactions on Computers* C-35(8), 677-691, 1986. doi:10.1109/TC.1986.1676819.

## `probstat.systems.dynamic`

### EQ-SYS-DFT-001 — Dynamic fault tree as an absorbing Markov chain

State `s = (D, u, V)`: failed basic events `D`, unit in use per spare gate
`u`, PAND gates with an out-of-order failure `V`. A working event `e` fails
at rate `lambda_e` when active, `alpha_e lambda_e` when it is an unused
spare, and `0` when it follows an unfailed SEQ input; after each failure
spare claims and FDEP cascades are resolved at the same instant. Gate
outputs: AND all, OR any, vote at least `k`, PAND all with `g not in V`,
SPARE no unit left, SEQ all. Every state with the top event is merged into
one absorbing state `FAIL`, and `F(t) = Pr(X_t = FAIL)` with
`pi(t) = pi(0) exp(Q t)`.

- Domain: non-repairable basic events with exponential lifetimes;
  dormancy `alpha` in `[0, 1]` (cold `0`, warm, hot `1`); simultaneous
  failures count as in order for PAND; simultaneous spare demands are
  served in gate declaration order.
- Meaning: exact quantification of order- and use-dependent failure
  logic; the transient law carries the uniformization error bound.
- Code: `systems.DynamicFaultTree.state_space`,
  `systems.DynamicFaultTree.unreliability`,
  `systems.DynamicFaultTree.reliability`, `systems.DFTStateSpace`.
- Source: [REF-DUGAN-BAVUSO-BOYD-1992], [REF-NASA-FTH-2002, Chapter 8],

### EQ-SYS-DFT-004 — Closed forms for elementary dynamic gates

## `probstat.systems.epistemic_ccf`

### EQ-SYS-ECCF-001 — Exact reliability polynomial in uncertain CCF parameters

Under the probability split `Q_k = c_k Q_t` the beta-factor coefficients
`c_1 = 1 - beta`, `c_m = beta` and the MGL coefficients
`c_k = (prod_(i=2)^k rho_i)(1 - rho_(k+1)) / C(m-1, k-1)` are products of
uncertain factors `theta` or `1 - theta` and a constant
`a = Q_t prod(fixed factors) / C(m-1, k-1)`; `Q_t` may itself be an
uncertain factor. Each CCF event probability is then a monomial
`a prod_l lit_l` in the basis `prod_i theta_i^(j_i) (1 - theta_i)^(k_i)`,
and its complement `1 - a prod_l lit_l` is written with non-negative
coefficients by expanding `1 = prod_l (lit_l + (1 - lit_l))`. The Shannon
recursion `P(f) = p_x P(f_1) + q_x P(f_0)` on the BDD of the expanded
structure yields `R(theta)` and `1 - R(theta)` as exact polynomials with
non-negative coefficients, and
`E[R] = sum_alpha c_alpha prod_i E[theta_i^(j_i) (1 - theta_i)^(k_i)]`
with the mixed moments of EQ-SYS-MOM-002. Equivalently, given the
parameters every event occurs when independent indicators (one constant
indicator and one Bernoulli(`theta`) indicator per factor) all fire, which
is the shared-block model of EQ-SYS-MOM-002.

- Domain: probability split; independent parameters with laws on `[0, 1]`
  (beta laws in closed form, other laws by quadrature of
  `q^j (1 - q)^k f(q)`); alpha-factor parameters and the hazard split are
  not polynomial and use EQ-SYS-ECCF-003.
- Meaning: epistemic CCF parameters are propagated exactly, without
  sampling and without cancellation in the means.
- Code: `systems.ccf_parameter_uncertainty`, `systems.EpistemicCCFResult`.
- Source: [REF-MOSLEH-ETAL-1998], [REF-APOSTOLAKIS-KAPLAN-1981],
  [REF-RAUZY-1993].

### EQ-SYS-ECCF-002 — Exact first-order variance shares

`S_theta = Var(E[R | theta_S]) / Var[R]` with
`Var(E[R | theta_S]) = E[g(theta_S, theta) g(theta_S, theta')] - E[g]^2`,
where `theta'` is an independent copy of the parameters outside `S` and `g`
is the reliability polynomial of EQ-SYS-ECCF-001 or its complement,
whichever has the smaller mean. Grouping the terms of `g` by their
exponents in `theta_S`, the cross moment is
`sum_(s, s') w_s w_s' prod_(i in S) E[theta_i^(j_s + j_s')
(1 - theta_i)^(k_s + k_s')]` with `w_s` the coefficients integrated over the
other parameters. `S` = all parameters gives `Var[R]`; `S` = all CCF
parameters gives the CCF share.

- Domain: as EQ-SYS-ECCF-001.
- Meaning: the fraction of the epistemic variance of `R` explained by
  CCF-parameter uncertainty (one when only CCF parameters are uncertain).
- Code: `systems.ccf_parameter_uncertainty`.

### EQ-SYS-ECCF-004 — Interval CCF parameters: monotone bounds and probability box

For interval parameters `theta in [a, b]` (a box), the unreliability is

- Domain: at most 10 interval parameters; monotonicity checked on a grid

### EQ-SYS-MKV-007 — Standby and load-sharing closed forms

## `probstat.systems.phased`

### EQ-SYS-PMS-001 — Phased-mission reliability

`R_mission = P(AND_j phi_j(x_{., j}) = 1)` with `x_{i,j} = [j < K_i]`;
`P(K_i = j) = prod_{l<j} s_{i,l} (1 - s_{i,j})` (per-phase models,
`s_{i,j} = R_{i,j}(d_j)`) or `R_i(T_{j-1}) - R_i(T_j)` (one model on the
cumulative time `T_j`); `P(K_i = J + 1)` is the survival probability.

- Domain: non-repairable components, monotone phase structures,
  instantaneous phase changes, independent components.
- Meaning: exact mission success probability; evaluated on a BDD with
  component-major order by enumerating each component's phase of failure at
  the first node of its variable block.
- Code: `systems.PhasedMission`, `systems.Phase`,
  `systems.PhasedMissionResult`.
- Source: [REF-ZANG-SUN-TRIVEDI-1999].

## `probstat.systems.phased_markov`

### EQ-SYS-MKPM-001 — Phased mission by phase-wise Markov propagation

`v_1 = alpha`; `w_i = v_i exp(Q~_i T_i)` with `Q~_i` the phase generator
whose failure states are absorbing when the requirement is continuous;
`S_i = sum_(j in G_i) w_ij`; `v_(i+1) = (w_i 1_(G_i)) H_(i+1)` with the
sub-stochastic phase-change matrix `H`. `Pr(mission success) = S_last`.

- Domain: finite phases with fixed durations; phase changes are
  instantaneous.
- Meaning: success requires meeting every phase requirement; the CTMC is
  homogeneous within each phase.
- Code: `systems.MarkovPhasedMission`, `systems.MissionPhase`.

### EQ-SYS-MKPM-002 — Discrete mission stages with absorbing outcomes

Stage `i` succeeds (`s_i`), retries (`r_i`), aborts (`a_i`) or fails
(`f_i`); `Pr(success) = prod_i s_i / (1 - r_i)`;
`T_i = (1 + s_i T_(i+1)) / (1 - r_i)`, `T_(n+1) = 0`; in general
`B = (I - Q)^-1 R` ([EQ-PROC-MC-005]).

- Domain: `r_i < 1`; probabilities per stage sum to one.
- Meaning: outcome probabilities and expected number of stage attempts.
- Code: `systems.discrete_mission_outcome`, `systems.MissionStageModel`.

## `probstat.systems.structure`

### EQ-SYS-STRUCT-001 — Series and parallel structures

`phi_series(x) = prod_i x_i`, `phi_parallel(x) = 1 - prod_i (1 - x_i)`;
for independent disjoint items `R = prod R_i` and `R = 1 - prod (1 - R_i)`.

- Domain: binary component states, `x_i = 1` means working.
- Meaning: the two elementary coherent structures; with repeated components
  the BDD composition (conjunction, disjunction) stays exact.
- Code: `systems.series`, `systems.parallel`, `systems.compile_expression`.
- Source: [REF-BARLOW-PROSCHAN-1975].

### EQ-SYS-STRUCT-002 — k-out-of-n:G structure

`phi(x) = [sum_i phi_i(x) >= k]`, built by
`T(i, j) = (phi_i and T(i + 1, j - 1)) or T(i + 1, j)`, `T(., 0) = TRUE`,
`T(n + 1, j > 0) = FALSE`; identical independent items give
`R = sum_{j >= k} C(n, j) p^j (1 - p)^(n - j)`.

- Domain: `1 <= k <= n`; items may be arbitrary monotone sub-structures.
- Meaning: voting redundancy; `O(n k)` BDD operations.
- Code: `systems.k_out_of_n`, `systems.compile_expression`.

### EQ-SYS-CCF-006 — Time-dependent CCF split (hazard or probability basis)

Probability basis: `Q_k(t) = c_k Q_t(t)`. Hazard basis: with the member's
cumulative hazard `H(t) = -log(1 - Q_t(t))`, `Q_k(t) = 1 - exp(-c_k H(t))`,
so that `1 - prod_k (1 - Q_k)^C(m - 1, k - 1) = Q_t(t)` exactly (by
EQ-SYS-CCF-004); for exponential members this is the rate split
`lambda_k = c_k lambda` (beta factor: `lambda_CCF = beta lambda`).

- Domain: symmetric groups; the two bases agree to first order in `Q_t`.
- Meaning: the hazard basis keeps each member's marginal failure probability
  equal to `Q_t(t)` over long missions (default for mission reliability);
  the probability basis is the NUREG/CR-5485 convention for demand and
  unavailability probabilities (default for availability).
- Code: `systems.SystemModel`, `systems.SystemModel.event_probabilities`.
- Source: [REF-MOSLEH-ETAL-1998], [REF-RAUSAND-HOYLAND-2004].
  - [REF-MOSLEH-ETAL-1998](../references.md#ref-mosleh-etal-1998): A. Mosleh, D. M. Rasmuson, and F. M. Marshall. *Guidelines on Modeling Common-Cause Failures in Probabilistic Risk Assessment*. NUREG/CR-5485 (INEEL/EXT-97-01327), U.S. Nuclear Regulatory Commission, 1998.
