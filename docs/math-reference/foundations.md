## `probstat.foundations.batch`

### EQ-BATCH-001 — Request and response of a batch procedure

`request_k = (x_1, ..., x_m; label)`; `response_k = (y_1, ..., y_m)` with
`y_i = f_label(x_i)`.

- Domain: `m >= 1` points of equal dimension; `label` names one model of the
  caller; the response has exactly `m` entries in request order.
- Meaning: an algorithm is a sequence of requests whose points may depend on
  all earlier responses. Its result is a function of the responses only, so
  it does not depend on how, where, or in how many chunks a request was
  evaluated. This is a software contract, not a statistical statement.
- Code: `foundations.EvaluationRequest`, `foundations.request`,
  `foundations.run_procedure`, `foundations.AskTellSession`,
  `foundations.batch_from_pointwise`, `foundations.scalar_outputs`,
  `foundations.vector_outputs`.
- Source: [REF-PEP-342].
  - [REF-PEP-342](../references.md#ref-pep-342): Guido van Rossum and Phillip J. Eby. "PEP 342 – Coroutines via Enhanced Generators." Python Enhancement Proposals, 2005. [https://peps.python.org/pep-0342/](https://peps.python.org/pep-0342/). Cited for `generator.send`, the mechanism by which a batch procedure receives the outputs of the evaluation request it yielded.
- Registry: [EQ-BATCH-001](../equation-registry.md#eq-batch-001--request-and-response-of-a-batch-procedure)

## `probstat.foundations.random_streams`

### EQ-RNG-SPLITMIX-001 — SplitMix64 seed derivation

`z <- (s + 0x9E3779B97F4A7C15) mod 2^64`,
`z <- (z xor (z >> 30)) * 0xBF58476D1CE4E5B9`,
`z <- (z xor (z >> 27)) * 0x94D049BB133111EB`, output `z xor (z >> 31)`; a
child seed is the mix of the parent seed XOR the mixed key.

- Domain: integer states modulo `2^64`; integer or UTF-8 text keys.
- Meaning: reproducible, order-independent named random streams that do not
  depend on Python's salted string hashing.
- Code: `foundations.splitmix64`, `foundations.derive_seed`,
  `foundations.RandomStream`.
- Source: [REF-STEELE-LEA-FLOOD-2014].
  - [REF-STEELE-LEA-FLOOD-2014](../references.md#ref-steele-lea-flood-2014): Guy L. Steele Jr., Doug Lea, and Christine H. Flood. "Fast Splittable Pseudorandom Number Generators." In *Proceedings of OOPSLA 2014*, ACM SIGPLAN Notices 49(10), 453-472, 2014.

## `probstat.foundations.validation`

### EQ-PROB-001 — Probability-measure bounds and axioms

`P(A) in [0, 1]`, `P(Omega) = 1`, and for pairwise disjoint `A_i`,
`P(union_i A_i) = sum_i P(A_i)`.

- Domain: `(Omega, F, P)` is a probability space.
- Meaning: valid event probabilities are normalized and countably additive.
- Code: `foundations.validation.require_probability`; distribution parameter
  validation.
- Source: [REF-KOLMOGOROV-1956, Chapter I, Section 2].
  - [REF-KOLMOGOROV-1956](../references.md#ref-kolmogorov-1956): A. N. Kolmogorov. *Foundations of the Theory of Probability*. 2nd English edition, translated by Nathan Morrison. Chelsea Publishing Company, 1956.
