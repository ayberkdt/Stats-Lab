## `probstat.statistics.bandwidth_selection`

### EQ-STAT-KDE-004 — Leave-one-out likelihood cross-validation

`L_LOO(h) = sum_i log((1/(n-1)) sum_(j != i) phi_h(x_i - x_j))`, with
`phi_h(u) = exp(-u^2/(2h^2)) / (h sqrt(2 pi))`; the selected bandwidth
maximizes `L_LOO`. The in-sample log-likelihood
`sum_i log((1/n) sum_j phi_h(x_i - x_j)) >= n log(1/(n h sqrt(2 pi)))`
tends to `+inf` as `h -> 0`. Derivative:
`dL_LOO/d log h = sum_i (sum_j D_ij^2 w_ij / sum_j w_ij) - n`,
`D_ij = (x_i - x_j)/h`, `w_ij = exp(-D_ij^2/2)`.

- Domain: `h > 0`; at least two observations. When every observation is
  repeated (heavily rounded data), `L_LOO` grows without bound as `h -> 0`.
- Meaning: the bandwidth that best predicts each observation from the
  others in Kullback-Leibler terms; sensitive to outliers and heavy tails,
  which pull it towards large `h`.
- Code: `statistics.bandwidth_selection.kde_loo_log_likelihood`,
  `statistics.bandwidth_selection.select_kde_bandwidth`.
- Source: [REF-DUIN-1976], [REF-SILVERMAN-1986, Section 3.4].

### EQ-STAT-KDE-005 — Unbiased and biased cross-validation scores

With `D = (x_i - x_j)/h` over pairs `i < j`:
`UCV(h) = 1/(2 n h sqrt(pi)) + (1/(n^2 h sqrt(pi))) sum (exp(-D^2/4) - sqrt(8) exp(-D^2/2))`
and
`BCV(h) = 1/(2 n h sqrt(pi)) + (1/(64 n^2 h sqrt(pi))) sum exp(-D^2/4)(D^4 - 12 D^2 + 12)`;
search interval `[0.1 h_os, h_os]`, `h_os = 1.144 s n^(-1/5)`.

- Domain: `h > 0`; pairs with `D^2 >= 1000` are dropped, as in R.
- Meaning: `UCV` estimates `ISE(h) - int f^2` (least-squares
  cross-validation); `BCV` is the asymptotic MISE with a kernel estimate of
  `int f''^2` and tends to zero as `h -> inf`, so its interior local minimum
  is used. R's `bw.ucv` and `bw.bcv` evaluate the same scores on binned
  pairwise distances.
- Code: `statistics.bandwidth_selection.kde_ucv`,
  `statistics.bandwidth_selection.kde_bcv`,
  `statistics.bandwidth_selection.oversmoothed_bandwidth`,
  `statistics.bandwidth_selection.select_kde_bandwidth`.

## `probstat.statistics.density`

### EQ-STAT-KDE-001 — Gaussian kernel density estimate and rule-of-thumb bandwidths

`f_h(x) = (1/(n h)) sum_i phi((x - x_i)/h)` and
`F_h(x) = (1/n) sum_i Phi((x - x_i)/h)`, with bandwidth
`h = 0.9 min(s, IQR/1.34) n^(-1/5)` (Silverman's robust rule) or
`h = 1.06 s n^(-1/5)` (normal reference rule).

- Domain: at least two finite observations, not all equal; `s` is the sample
  standard deviation and `IQR` the type-7 interquartile range (a zero IQR
  falls back to `s`).
- Meaning: a smooth, everywhere-positive estimate of the sampling density;
  the normal rule minimizes the asymptotic mean integrated squared error for
  normal data and oversmooths multimodal data, which the robust rule
  mitigates.
- Code: `statistics.density.gaussian_kde`, `statistics.density.kde_bandwidth`,
  `statistics.density.KernelDensity`.
- Source: [REF-SILVERMAN-1986, Sections 3.3 and 3.4.2].
  - [REF-SILVERMAN-1986](../references.md#ref-silverman-1986): B. W. Silverman. *Density Estimation for Statistics and Data Analysis*. Chapman and Hall, 1986.

## `probstat.statistics.multivariate_density`

### EQ-STAT-KDE-006 — Multivariate Gaussian KDE with a covariance-shaped kernel

`f_h(x) = (1/N) sum_i phi_d(x - x_i; h^2 R)`, `R` the sample covariance
(divisor `N - 1`); Silverman's factor `h = (4 / (N (d + 2)))^(1/(d+4))`,
Scott's factor `h = N^(-1/(d+4))`; the leave-one-out log-likelihood
`sum_i log((1/(N-1)) sum_(j != i) phi_d(x_i - x_j; h^2 R))` selects `h`.
The estimate has mean `xbar` and covariance `((N - 1)/N + h^2) R`; draws are
`x_J + h L Z` with `R = L L'`.

- Domain: `N > d`, `R` positive definite, `h > 0`.
- Meaning: every kernel has the shape of the data cloud, so one scalar
  factor smooths all directions in proportion to their spread; the
  normal-reference factor oversmooths multimodal or curved data.
- Code: `statistics.multivariate_density.gaussian_kde_multivariate`,
  `statistics.multivariate_density.multivariate_kde_factor`,
  `statistics.multivariate_density.multivariate_kde_loo_log_likelihood`,
  `statistics.multivariate_density.MultivariateKernelDensity`.

### EQ-STAT-QUANT-002 — The nine Hyndman-Fan sample quantiles

Every type is `Q(p) = (1 - gamma) x_(j) + gamma x_(j+1)` with
`x_(0) = x_(1)` and `x_(n+1) = x_(n)`. Discontinuous types use
`j = floor(n p + m)`, `g = n p + m - j`: type 1 (`m = 0`, `gamma = 0` if
`g = 0`, else 1), type 2 (`m = 0`, `gamma = 1/2` if `g = 0`, else 1), type 3
(`m = -1/2`, `gamma = 0` if `g = 0` and `j` is even, else 1). Continuous types
interpolate between the plotting positions `p_k = (k - alpha)/(n + 1 -
alpha - beta)`: `h = alpha + p (n + 1 - alpha - beta)`, `j = floor(h)`,
`gamma = h - j`, with `(alpha, beta) = (0, 1)` (type 4), `(1/2, 1/2)` (5),
`(0, 0)` (6), `(1, 1)` (7), `(1/3, 1/3)` (8), and `(3/8, 3/8)` (9).

- Domain: non-empty finite sample and `p in [0,1]`; the position is formed
  in exact rational arithmetic and taken to be the integer `k` when `p` is
  the floating-point value of the level at which it equals `k`.
- Meaning: types 1-3 are step functions of `p` (inverse empirical CDF,
  averaged at the jumps, nearest even order statistic); types 4-9 are
  continuous. Types 2 and 5-9 give the usual median and satisfy
  `Q_x(p) = -Q_(-x)(1 - p)`; type 8 is approximately median-unbiased for any
  continuous law and type 9 approximately unbiased for normal data.
- Code: `statistics.quantile`, `statistics.quantiles`.
- Source: [REF-HYNDMAN-FAN-1996].
  - [REF-HYNDMAN-FAN-1996](../references.md#ref-hyndman-fan-1996): Rob J. Hyndman and Yanan Fan. "Sample Quantiles in Statistical Packages." *The American Statistician* 50(4), 361-365, 1996.
- Registry: [EQ-STAT-QUANT-002](../equation-registry.md#eq-stat-quant-002--the-nine-hyndman-fan-sample-quantiles)

### EQ-STAT-SHAPE-002 — Bias-adjusted skewness and kurtosis (G1, G2, b1, b2)

With `g1 = m3 / m2^(3/2)` and `g2 = m4 / m2^2 - 3` [EQ-STAT-SHAPE-001]:
`G1 = g1 sqrt(n (n - 1)) / (n - 2)`,
`G2 = ((n + 1) g2 + 6)(n - 1) / ((n - 2)(n - 3))`,
`b1 = g1 ((n - 1)/n)^(3/2) = m3 / s^3`, and
`b2 = (g2 + 3)(1 - 1/n)^2 - 3 = m4 / s^4 - 3`, where `s^2` has divisor
`n - 1`.

- Domain: positive `m2`; `n >= 3` for `G1` and `n >= 4` for `G2`.
- Meaning: `G1 = k3 / k2^(3/2)` and `G2 = k4 / k2^2` are ratios of the
  unbiased cumulant estimators (k-statistics); `b1` and `b2` standardize by
  the sample standard deviation. The three conventions agree as `n` grows.
  Under normality every skewness has mean zero by symmetry, and of the
  kurtosis measures only `G2` is unbiased (`E[g2] = -6/(n + 1)`). e1071
  types 1, 2, and 3 are `g`, `G`, and `b`; SAS and SPSS report `G`, MINITAB
  and BMDP `b`.
- Code: `statistics.skewness`, `statistics.excess_kurtosis`.
- Source: [REF-JOANES-GILL-1998].
  - [REF-JOANES-GILL-1998](../references.md#ref-joanes-gill-1998): D. N. Joanes and C. A. Gill. "Comparing Measures of Sample Skewness and Kurtosis." *Journal of the Royal Statistical Society, Series D (The Statistician)* 47(1), 183-189, 1998.
- Registry: [EQ-STAT-SHAPE-002](../equation-registry.md#eq-stat-shape-002--bias-adjusted-skewness-and-kurtosis-g1-g2-b1-b2)

### EQ-STAT-TRIM-001 — Symmetric trimmed mean

`g = floor(alpha n)`, `T_alpha = (1 / (n - 2g)) sum_{i=g+1}^{n-g} x_(i)` with
order statistics `x_(1) <= ... <= x_(n)`.

- Domain: `0 <= alpha < 1/2`, `n >= 1` finite observations.
- Meaning: removes the `g` smallest and `g` largest observations before
  averaging; `alpha = 0` is the mean and `alpha -> 1/2` approaches the median.
  On real measurement series, light trimming improved somewhat on the
  sample mean [REF-STIGLER-1977, abstract].
- Code: `statistics.trimmed_mean`.
- Source: [REF-STIGLER-1977] (comparison of trimmed means and other location
  estimators on historical measurement series).

## `probstat.statistics.streaming`

### EQ-STAT-STREAM-001 — Shifted Welford update of the mean and second central sum

With shift `K = x_1`, `y_i = x_i - K`, running mean `a_n` of the `y_i`, and
`M2_n = sum_{i<=n} (y_i - a_n)^2`: `delta = y_n - a_{n-1}`,
`a_n = a_{n-1} + delta / n`, `M2_n = M2_{n-1} + delta^2 (n - 1) / n`; the
reported mean is `K + a_n` and the variance `M2_n / (n - d)`.

- Domain: finite real observations, `n >= 1`; `0 <= d < n` for the variance.
- Meaning: one pass, constant memory. Central sums are shift invariant, and
  for data with a large common offset `x_i - K` is exact, so the recurrence
  runs on well-scaled numbers (2000 values `1e9 + Exp(1)`: relative variance
  error `3.5e-16`, unshifted Welford `2.0e-8`).
- Code: `statistics.RunningMoments`, `statistics.RunningCovariance`,
  `monte_carlo.estimate_mean_streaming`.
- Source: [REF-WELFORD-1962], [REF-CHAN-GOLUB-LEVEQUE-1983] (shifted data).
  - [REF-WELFORD-1962](../references.md#ref-welford-1962): B. P. Welford. "Note on a Method for Calculating Corrected Sums of Squares and Products." *Technometrics* 4(3), 419-420, 1962. DOI: [10.2307/1266577](https://doi.org/10.2307/1266577).
  - [REF-CHAN-GOLUB-LEVEQUE-1983](../references.md#ref-chan-golub-leveque-1983): Tony F. Chan, Gene H. Golub, and Randall J. LeVeque. "Algorithms for Computing the Sample Variance: Analysis and Recommendations." *The American Statistician* 37(3), 242-247, 1983. DOI: [10.1080/00031305.1983.10483115](https://doi.org/10.1080/00031305.1983.10483115).
- Also names: [`monte_carlo`](monte_carlo.md)
- Registry: [EQ-STAT-STREAM-001](../equation-registry.md#eq-stat-stream-001--shifted-welford-update-of-the-mean-and-second-central-sum)

### EQ-STAT-STREAM-002 — Pairwise merge of means, second central sums, and co-moments

For disjoint chunks `A`, `B` with counts `n_A`, `n_B`, `n = n_A + n_B`, and
`delta = mean_B - mean_A`: `mean = mean_A + delta n_B / n`,
`M2 = M2_A + M2_B + delta^2 n_A n_B / n`, and for vectors
`C_jk = C_A,jk + C_B,jk + delta_j delta_k n_A n_B / n`.

- Domain: `n_A, n_B >= 1`; an empty chunk is the identity.
- Meaning: summaries of chunks combine into the summary of the concatenated
  data, so the computation parallelizes; the single-value update of
  [EQ-STAT-STREAM-001] is the case `n_B = 1`.
- Code: `statistics.RunningMoments.merge`, `statistics.RunningCovariance`.
- Source: [REF-CHAN-GOLUB-LEVEQUE-1983], [REF-PEBAY-2008].
  - [REF-CHAN-GOLUB-LEVEQUE-1983](../references.md#ref-chan-golub-leveque-1983): Tony F. Chan, Gene H. Golub, and Randall J. LeVeque. "Algorithms for Computing the Sample Variance: Analysis and Recommendations." *The American Statistician* 37(3), 242-247, 1983. DOI: [10.1080/00031305.1983.10483115](https://doi.org/10.1080/00031305.1983.10483115).
  - [REF-PEBAY-2008](../references.md#ref-pebay-2008): Philippe Pébay. "Formulas for Robust, One-Pass Parallel Computation of Covariances and Arbitrary-Order Statistical Moments." Sandia National Laboratories technical report SAND2008-6212, 2008. OSTI ID 1028931. [https://www.osti.gov/biblio/1028931](https://www.osti.gov/biblio/1028931).

### EQ-STAT-STREAM-003 — Pairwise merge of third and fourth central sums

With the notation of [EQ-STAT-STREAM-002]:
`M3 = M3_A + M3_B + delta^3 n_A n_B (n_A - n_B) / n^2
+ 3 delta (n_A M2_B - n_B M2_A) / n` and
`M4 = M4_A + M4_B + delta^4 n_A n_B (n_A^2 - n_A n_B + n_B^2) / n^3
+ 6 delta^2 (n_A^2 M2_B + n_B^2 M2_A) / n^2 + 4 delta (n_A M3_B - n_B M3_A) / n`.
Then `g1 = sqrt(n) M3 / M2^(3/2)` and `g2 = n M4 / M2^2 - 3`.

- Domain: as [EQ-STAT-STREAM-002]; `M2 > 0` for `g1`, `g2`.
- Meaning: one-pass, mergeable skewness and kurtosis equal to
  [EQ-STAT-SHAPE-001]; with `n_B = 1` and `M2_B = M3_B = M4_B = 0` this is the
  streaming update.
- Code: `statistics.RunningMoments`.
- Source: [REF-PEBAY-2008].
  - [REF-PEBAY-2008](../references.md#ref-pebay-2008): Philippe Pébay. "Formulas for Robust, One-Pass Parallel Computation of Covariances and Arbitrary-Order Statistical Moments." Sandia National Laboratories technical report SAND2008-6212, 2008. OSTI ID 1028931. [https://www.osti.gov/biblio/1028931](https://www.osti.gov/biblio/1028931).
- Registry: [EQ-STAT-STREAM-003](../equation-registry.md#eq-stat-stream-003--pairwise-merge-of-third-and-fourth-central-sums)

### EQ-STAT-STREAM-004 — West's weighted update and weighted-variance conventions

For weight `w > 0`: `W' = W + w`, `delta = x - mean`, `R = delta w / W'`,
`mean' = mean + R`, `S' = S + W delta R`; merge
`S = S_A + S_B + delta^2 W_A W_B / W`. Variances: population `S / W`,
frequency `S / (W - 1)`, reliability `S / (W - V / W)` with `V = sum w_i^2`;
effective sample size `W^2 / V`.

- Domain: finite values, finite non-negative weights, `W > 0`; each
  denominator must be positive.
- Meaning: `S = sum w_i (x_i - mean)^2` and `mean = sum w_i x_i / W` in one
  pass; the convention states whether weights are repeat counts or relative
  precisions.
- Code: `statistics.WeightedRunningMoments`.
- Source: [REF-WEST-1979], [REF-CHAN-GOLUB-LEVEQUE-1983].
  - [REF-WEST-1979](../references.md#ref-west-1979): D. H. D. West. "Updating Mean and Variance Estimates: An Improved Method." *Communications of the ACM* 22(9), 532-535, 1979. DOI: [10.1145/359146.359153](https://doi.org/10.1145/359146.359153).
  - [REF-CHAN-GOLUB-LEVEQUE-1983](../references.md#ref-chan-golub-leveque-1983): Tony F. Chan, Gene H. Golub, and Randall J. LeVeque. "Algorithms for Computing the Sample Variance: Analysis and Recommendations." *The American Statistician* 37(3), 242-247, 1983. DOI: [10.1080/00031305.1983.10483115](https://doi.org/10.1080/00031305.1983.10483115).

### EQ-STAT-STREAM-005 — P² marker adjustment

Markers at heights `q_1..q_5` and integer positions `n_1..n_5` with desired
positions `n'_i` advancing by `(0, p/2, p, (1+p)/2, 1)` per observation. If
`d = n'_i - n_i` satisfies `d >= 1, n_{i+1} - n_i > 1` or
`d <= -1, n_{i-1} - n_i < -1`, set `s = sign(d)`,
`q_i <- q_i + s / (n_{i+1} - n_{i-1}) [ (n_i - n_{i-1} + s)(q_{i+1} - q_i) /
(n_{i+1} - n_i) + (n_{i+1} - n_i - s)(q_i - q_{i-1}) / (n_i - n_{i-1}) ]`
when this stays strictly between `q_{i-1}` and `q_{i+1}`, else the linear
`q_i + s (q_{i+s} - q_i) / (n_{i+s} - n_i)`; then `n_i <- n_i + s`.

- Domain: `0 < p < 1`, at least six observations (exact type-7 quantile
  before).
- Meaning: five-number fixed-memory estimate `q_3` of the `p`-quantile; a
  heuristic without a worst-case error bound and not mergeable.
- Code: `statistics.P2Quantile`.
- Source: [REF-JAIN-CHLAMTAC-1985].
  - [REF-JAIN-CHLAMTAC-1985](../references.md#ref-jain-chlamtac-1985): Raj Jain and Imrich Chlamtac. "The P² Algorithm for Dynamic Calculation of Quantiles and Histograms Without Storing Observations." *Communications of the ACM* 28(10), 1076-1085, 1985. Author copy: [https://classes.engineering.wustl.edu/~jain/papers/ftp/psqr.pdf](https://classes.engineering.wustl.edu/~jain/papers/ftp/psqr.pdf).
- Registry: [EQ-STAT-STREAM-005](../equation-registry.md#eq-stat-stream-005--p²-marker-adjustment)

### EQ-STAT-STREAM-006 — Reservoir sampling (Algorithm R)

Keep the first `k` items; for item `t > k` draw `J` uniform on
`{1, ..., t}` and replace slot `J` when `J <= k`. After `n` items each item is
retained with probability `min(1, k / n)` and every `k`-subset is equally
likely.

- Domain: capacity `k >= 1`; a uniform integer generator.
- Meaning: an exact uniform random subsample of fixed size from a stream of
  unknown length.
- Code: `statistics.ReservoirSampler`.
- Source: [REF-VITTER-1985].
  - [REF-VITTER-1985](../references.md#ref-vitter-1985): Jeffrey Scott Vitter. "Random Sampling with a Reservoir." *ACM Transactions on Mathematical Software* 11(1), 37-57, 1985. DOI: [10.1145/3147.3165](https://doi.org/10.1145/3147.3165).
- Registry: [EQ-STAT-STREAM-006](../equation-registry.md#eq-stat-stream-006--reservoir-sampling-algorithm-r)

### EQ-STAT-STREAM-007 — Relative-standard-error stopping rule

`r_n = s_n / (sqrt(n) |mean_n|)` with `s_n^2 = M2_n / (n - 1)`; stop at the
first check `n in {n_0, n_0 + h, n_0 + 2h, ...}` with `r_n <= epsilon`, or at
`n = N_max`.

- Domain: `n >= 2`, `epsilon > 0`, `n_0 >= 2`, `h >= 1`; `r_n = inf` when
  `mean_n = 0` and `s_n > 0`.
- Meaning: a fixed relative precision target for a running Monte Carlo mean,
  with constant memory; data-dependent stopping makes `r_n` slightly
  optimistic.
- Code: `statistics.run_until`, `statistics.RunningMoments`,
  `monte_carlo.estimate_mean_streaming`.
- Source: [REF-ROBERT-CASELLA-2004, Chapters 3-4] ([EQ-MC-SE-001]).
