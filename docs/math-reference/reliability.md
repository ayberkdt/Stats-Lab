## `probstat.reliability.active_learning`

### EQ-REL-AKMCS-001 — AK-MCS learning function and stopping rule

`U(u) = |mu_G(u)| / sigma_G(u)` from the GP posterior of `G`; next point
`u* = argmin_(i not in T) U(u_i)` over the Monte Carlo population; stop when
`min_i U(u_i) >= 2`.

- Domain: GP surrogate of `G` in standard-normal space; fixed population.
- Meaning: `Phi(-U)` is the posterior probability that the predicted sign
  of `G(u_i)` is wrong, so `min U >= 2` bounds every point's misclassification
  probability by `Phi(-2) ~ 0.023`. Between hyperparameter fits the
  posterior is updated by exact rank-one Cholesky updates.
- Code: `reliability.ak_mcs`.
- Source: [REF-ECHARD-GAYTON-LEMAIRE-2011] and
  [REF-RASMUSSEN-WILLIAMS-2006, Algorithm 2.1].
  - [REF-ECHARD-GAYTON-LEMAIRE-2011](../references.md#ref-echard-gayton-lemaire-2011): B. Echard, N. Gayton, and M. Lemaire. "AK-MCS: An Active Learning Reliability Method Combining Kriging and Monte Carlo Simulation." *Structural Safety* 33(2), 145-154, 2011. DOI: [10.1016/j.strusafe.2011.01.002](https://doi.org/10.1016/j.strusafe.2011.01.002).
  - [REF-RASMUSSEN-WILLIAMS-2006](../references.md#ref-rasmussen-williams-2006): Carl Edward Rasmussen and Christopher K. I. Williams. *Gaussian Processes for Machine Learning*. MIT Press, 2006.

### EQ-REL-AKMCS-002 — AK-MCS population estimate and coefficient of variation

`P_f_hat = N_f / N` with `N_f = #{i : mu_G(u_i) <= 0}`;
`c.o.v. = sqrt((1 - P_f_hat) / (N P_f_hat))`; the population is enlarged
while the c.o.v. exceeds the target.

- Domain: `N_f > 0`; the c.o.v. is the Monte Carlo error of the population
  and excludes surrogate misclassification.
- Meaning: crude Monte Carlo on the population with the surrogate's sign in
  place of the true indicator.
- Code: `reliability.ak_mcs`.
- Source: [REF-ECHARD-GAYTON-LEMAIRE-2011] and [REF-OWEN-2013, Chapter 2].

## `probstat.reliability.adaptive`

### EQ-REL-CE-001 — Cross-entropy levels and Gaussian parameter update

`gamma_t = max(q_rho(G(u_1..u_N)), 0)` for `u_k ~ h_(t-1) = N(mu, Sigma)`;
with elite set `E_t = {k : G(u_k) <= gamma_t}` and likelihood ratios
`W_k = phi_n(u_k) / h_(t-1)(u_k)`,
`mu_t = sum_(E_t) W_k u_k / sum_(E_t) W_k` and
`Sigma_t = sum_(E_t) W_k (u_k - mu_t)(u_k - mu_t)' / sum_(E_t) W_k`.

- Domain: standard-normal space of the Nataf map; `0 < rho <= 1/2`;
  covariance adaptation needs at least `d + 1` elite points.
- Meaning: weighted maximum likelihood of the Gaussian family for the
  conditional law `phi_n(u) I(G(u) <= gamma_t)`, which minimizes the
  Kullback-Leibler (cross-entropy) distance to it; the levels end at
  `gamma = 0`.
- Code: `reliability.cross_entropy_importance_sampling`.
- Source: [REF-RUBINSTEIN-KROESE-2004] and [REF-KURTZ-SONG-2013].
  - [REF-RUBINSTEIN-KROESE-2004](../references.md#ref-rubinstein-kroese-2004): Reuven Y. Rubinstein and Dirk P. Kroese. *The Cross-Entropy Method: A Unified Approach to Combinatorial Optimization, Monte-Carlo Simulation, and Machine Learning*. Springer, 2004.
  - [REF-KURTZ-SONG-2013](../references.md#ref-kurtz-song-2013): Nolan Kurtz and Junho Song. "Cross-Entropy-Based Adaptive Importance Sampling Using Gaussian Mixture." *Structural Safety* 42, 35-44, 2013.
- Registry: [EQ-REL-CE-001](../equation-registry.md#eq-rel-ce-001--cross-entropy-levels-and-gaussian-parameter-update)

### EQ-REL-CE-002 — Gaussian-proposal importance-sampling estimate

`P_f_hat = (1/N) sum_k I(G(u_k) <= 0) w(u_k)` with `u_k ~ N(mu, LL')` and
`log w(u) = -||u||^2/2 + ||z||^2/2 + log det L`, `z = L^-1 (u - mu)`;
`c.o.v. = SE(P_f_hat) / P_f_hat`.

- Domain: proposal with full support (positive-definite `LL'`).
- Meaning: unbiased for any such proposal; the normalizing constants of
  both Gaussians cancel in the weight.
- Code: `reliability.cross_entropy_importance_sampling`,
  `reliability.compare_reliability_methods` (row `"CE-IS"`).
- Source: [REF-RUBINSTEIN-KROESE-2004] and [REF-OWEN-2013, Chapter 9].
  - [REF-RUBINSTEIN-KROESE-2004](../references.md#ref-rubinstein-kroese-2004): Reuven Y. Rubinstein and Dirk P. Kroese. *The Cross-Entropy Method: A Unified Approach to Combinatorial Optimization, Monte-Carlo Simulation, and Machine Learning*. Springer, 2004.

### EQ-REL-LINE-001 — Line-sampling estimator and variance

For unit `alpha` and `u_k ~ N(0, I)`, `u_perp = u_k - (alpha . u_k) alpha`,
`G(u_perp + c_k alpha) = 0`, `p_k = Phi(-c_k)`;
`P_f_hat = (1/N) sum_k p_k` and
`Var(P_f_hat) = sum_k (p_k - P_f_hat)^2 / (N (N - 1))`.

- Domain: each line crosses the limit state at most once, with failure on
  the side of increasing `c`; lines without a crossing in `|c| <= c_max`
  contribute 0 (always safe) or 1 (always failed).
- Meaning: conditional Monte Carlo that integrates the coordinate along
  `alpha` exactly; for a planar limit state orthogonal to `alpha` every
  `p_k = Phi(-beta)` and the variance is zero.
- Code: `reliability.line_sampling`,
  `reliability.compare_reliability_methods` (row `"Line"`).
- Source: [REF-KOUTSOURELAKIS-PRADLWARTER-SCHUELLER-2004].
  - [REF-KOUTSOURELAKIS-PRADLWARTER-SCHUELLER-2004](../references.md#ref-koutsourelakis-pradlwarter-schueller-2004): Phaedon-Stelios Koutsourelakis, Helmut J. Pradlwarter, and Gerhart I. Schuëller. "Reliability of Structures in High Dimensions, Part I: Algorithms and Applications." *Probabilistic Engineering Mechanics* 19(4), 409-417, 2004.

### EQ-REL-CE-003 — Finite importance-weight variance of a Gaussian proposal

For `h = N(mu, Sigma)` and `w = phi_n / h`,
`E_h[w^2] = int phi_n(u)^2 / h(u) du` is finite if and only if
`I - Sigma^-1 / 2` is positive definite, i.e. every eigenvalue of `Sigma`
exceeds `1/2`. The CE guard replaces `Sigma = V diag(lambda) V'` by
`V diag(max(lambda_i, lambda_min)) V'` with `lambda_min > 1/2`
(default `0.55`).

- Domain: unbounded failure domains in standard-normal space; the guard is
  applied to every adapted CE covariance.
- Meaning: `phi_n^2 / h` has the quadratic exponent
  `-u'(I - Sigma^-1 / 2) u + O(u)`; when it is not negative definite the
  weights have infinite variance, so the sample variance (and the reported
  c.o.v.) cannot represent the error. Elite covariances of near-planar
  failure domains collapse along the important direction and violate the
  condition.
- Code: `reliability.cross_entropy_importance_sampling`
  (`covariance_floor`, `min_covariance_eigenvalue`, `weights_degenerate`).
- Source: [REF-OWEN-2013, Chapter 9] (importance-sampling variance and
  light-tailed proposals); the eigenvalue condition is a direct Gaussian
  integral.
  - [REF-OWEN-2013](../references.md#ref-owen-2013): Art B. Owen. *Monte Carlo Theory, Methods and Examples*. 2013. [https://artowen.su.domains/mc/](https://artowen.su.domains/mc/).
- Registry: [EQ-REL-CE-003](../equation-registry.md#eq-rel-ce-003--finite-importance-weight-variance-of-a-gaussian-proposal)

### EQ-REL-CE-004 — Coverage of the first-level elite set by a CE proposal

With `E_1` the elite points of the first cross-entropy level (drawn from the
starting density) and `mu` the final proposal mean,
`f = #{u in E_1 : u . mu / ||mu|| <= 0} / |E_1|`, computed only when
`||mu|| >= 1`; CE-IS warns when `f > 0.1`.

- Domain: `||mu|| >= 1` (`f = nan` otherwise); standard-normal space.
- Meaning: one convex or near-planar failure region `{u . alpha >= beta}`
  has all elite points at `u . alpha >= q > 0`, so `f` is near `0`; elite
  points behind the origin as seen from the proposal belong to a failure
  region the single Gaussian proposal does not sample, whose probability
  is then missed (four-branch system: `f` about `0.5`, estimate about a
  quarter to a third of the exact value).
- Code: `reliability.cross_entropy_importance_sampling`.
- Source: [REF-RUBINSTEIN-KROESE-2004], [REF-KURTZ-SONG-2013].
  - [REF-RUBINSTEIN-KROESE-2004](../references.md#ref-rubinstein-kroese-2004): Reuven Y. Rubinstein and Dirk P. Kroese. *The Cross-Entropy Method: A Unified Approach to Combinatorial Optimization, Monte-Carlo Simulation, and Machine Learning*. Springer, 2004.
  - [REF-KURTZ-SONG-2013](../references.md#ref-kurtz-song-2013): Nolan Kurtz and Junho Song. "Cross-Entropy-Based Adaptive Importance Sampling Using Gaussian Mixture." *Structural Safety* 42, 35-44, 2013.

## `probstat.reliability.ak_subset`

### EQ-REL-AKSS-001 — AK-SS: active learning on surrogate subset levels

Round `r`: subset simulation on the surrogate mean `mu_r(u)` with `N`
samples per level and level probability `p0` gives
`P_r = p0^(m-1) #{i : mu_r(u_i^(m)) <= 0} / N` over the `N` samples
`u_i^(m)` of the last level; the pool `C_r` is the set of distinct samples
of all levels. While `min_(u in C_r \ T) U(u) < 2` with
`U = |mu| / sigma`, the model is evaluated at the arg min, which joins the
training set `T`, and the posterior over `C_r` is updated; then round
`r + 1` starts. The iteration stops with `P_r` when the stop of
[EQ-REL-AKSS-002] holds or when `C_r` needs no addition, in both cases on a
GP fitted to all of `T`.

- Domain: GP surrogate of `G` in standard-normal space; every round uses the
  same random stream for the subset run (common random numbers).
- Meaning: the subset levels place the candidates on the path from the bulk
  of the input law to the failure domain, so a few thousand candidates per
  level stand for a failure probability far below `1 / (number of
  candidates)`. `P_r` estimates `P(mu_r <= 0)`; its subset c.o.v. excludes
  the misclassification by the surrogate.
- Code: `reliability.ak_ss`.
- Source: [REF-HUANG-CHEN-ZHU-2016] (subset simulation on the Kriging
  predictor, level samples as candidates); [REF-ECHARD-GAYTON-LEMAIRE-2011]
  (`U` and `min U >= 2`); [REF-AU-BECK-2001] (subset levels). The pool
  definition, the common random numbers, and the stopping logic are
  implementation choices of this library.
  - [REF-HUANG-CHEN-ZHU-2016](../references.md#ref-huang-chen-zhu-2016): Xiaoxu Huang, Jianqiao Chen, and Hongping Zhu. "Assessing Small Failure Probabilities by AK-SS: An Active Learning Method Combining Kriging and Subset Simulation." *Structural Safety* 59, 86-95, 2016. Subset simulation run on the Kriging predictor, with the samples of the subset levels as the candidates of active learning by the `U` function. DOI: [10.1016/j.strusafe.2015.12.003](https://doi.org/10.1016/j.strusafe.2015.12.003).
  - [REF-ECHARD-GAYTON-LEMAIRE-2011](../references.md#ref-echard-gayton-lemaire-2011): B. Echard, N. Gayton, and M. Lemaire. "AK-MCS: An Active Learning Reliability Method Combining Kriging and Monte Carlo Simulation." *Structural Safety* 33(2), 145-154, 2011. DOI: [10.1016/j.strusafe.2011.01.002](https://doi.org/10.1016/j.strusafe.2011.01.002).
  - [REF-AU-BECK-2001](../references.md#ref-au-beck-2001): Siu-Kui Au and James L. Beck. "Estimation of Small Failure Probabilities in High Dimensions by Subset Simulation." *Probabilistic Engineering Mechanics* 16(4), 263-277, 2001.
- Registry: [EQ-REL-AKSS-001](../equation-registry.md#eq-rel-akss-001--ak-ss-active-learning-on-surrogate-subset-levels)

### EQ-REL-AKSS-002 — AK-SS stop on the last level's failure-count bounds

`P^- = p0^(m-1) #{i : mu(u_i^(m)) + 1.96 sigma(u_i^(m)) <= 0} / N`,
`P^+ = p0^(m-1) #{i : mu(u_i^(m)) - 1.96 sigma(u_i^(m)) <= 0} / N` over the
`N` samples of the last level (chain repetitions counted); stop when the run
reached the threshold `0`, `P_r > 0`, and `(P^+ - P^-) / P_r <= tolerance`
(default `0.05`).

- Domain: a subset run on the surrogate mean with predictive variances at
  its last-level samples.
- Meaning: flipping every last-level sign that is uncertain at level 1.96
  moves the estimate by at most the tolerance (relative), given the levels.
  The bounds are as overconfident as the surrogate's `sigma` and do not see
  failure regions that the subset run never sampled.
- Code: `reliability.ak_ss`.
- Source: the bound rule of [REF-SCHOBI-SUDRET-MARELLI-2017], applied here
  to the last subset level (an implementation choice of this library).
  - [REF-SCHOBI-SUDRET-MARELLI-2017](../references.md#ref-schobi-sudret-marelli-2017): R. Schöbi, B. Sudret, and S. Marelli. "Rare Event Estimation Using Polynomial-Chaos Kriging." *ASCE-ASME Journal of Risk and Uncertainty in Engineering Systems, Part A: Civil Engineering* 3(2), D4016002, 2017. Failure-probability bounds from `mu -/+ 1.96 sigma` and the relative-width stopping rule of active learning. DOI: [10.1061/AJRUA6.0000870](https://doi.org/10.1061/AJRUA6.0000870).
- Registry: [EQ-REL-AKSS-002](../equation-registry.md#eq-rel-akss-002--ak-ss-stop-on-the-last-levels-failure-count-bounds)

### EQ-REL-ALLOC-005 — Series cost-optimal allocation (KKT)

Minimise `sum c_i(R_i)` s.t. `sum ln R_i >= ln R*`: `R_i c_i'(R_i) = mu`
(interior) or `R_i = l_i` when `l_i c_i'(l_i) >= mu`; `mu` from
`sum ln R_i(mu) = ln R*`.

- Domain: convex increasing costs; solved in log space.
- Meaning: exact optimum for series systems.
- Code: `reliability.cost_optimal_series_allocation`.

### EQ-REL-ALLOC-006 — Augmented Lagrangian allocation

### EQ-REL-LIMIT-001 — Limit-state failure convention

`failure = {x : g(x) <= 0}` and `safe = {x : g(x) > 0}`.

- Domain: a finite deterministic scalar limit-state evaluation on each input.
- Meaning: zero belongs to the closed failure domain, so every reliability
  method uses one explicit and consistent boundary convention.
- Code: `reliability.LimitState.evaluate` and `LimitState.failed`.
- Source: [REF-MELCHERS-BECK-2018, Chapter 3].

### EQ-REL-PF-001 — Failure probability and reliability

`P_f=P(g(X)<=0)=E[I(g(X)<=0)]` and `R=1-P_f`.

- Domain: a probabilistic input model and measurable failure event.
- Meaning: direct Monte Carlo estimates the Bernoulli event and retains a
  Wilson interval, including a nonzero upper bound after zero observed failures.
- Code: `reliability.estimate_failure_probability`.
- Source: [REF-MELCHERS-BECK-2018, Chapters 3 and 5].

### EQ-REL-IS-001 — Importance-weighted failure estimator

`P_f=E_q[I(g(X)<=0) p(X)/q(X)]`.

- Domain: proposal support covers the target failure contribution, likelihood
  ratios are correct and non-negative, and weighted contributions have finite
  variance for the usual error interpretation.
- Meaning: proposal draws can deliberately visit a rare failure region while
  ordinary importance weights preserve the target probability.
- Code: `reliability.estimate_weighted_failure_probability`.

### EQ-REL-CERT-001 — Monte Carlo certification rule and normal margin

Certify when `p_hat_n + c(n, alpha, beta) <= alpha` with
`p_hat_n = (1/n) sum_i 1{y(x_i) > S}` and
`c(n, alpha, beta) = z_(1-beta) sqrt(alpha (1 - alpha) / n)`;
`max_(p_f >= alpha) P(certify) -> beta` as `n -> infinity`.

- Domain: `n` independent model runs, acceptable risk `0 < alpha < 1`,
  false-certification probability `0 < beta < 1`, `z_(1-beta)` the
  standard-normal quantile.
- Meaning: the margin turns the estimate into a decision whose probability
  of accepting a system with `p_f >= alpha` is asymptotically `beta`; for
  small `n alpha` it is only approximate.
- Code: `reliability.certification_margin`,
  `reliability.certification_probability`,

### EQ-REL-CERT-002 — Exact certification probability under a binomial count

With `X ~ Binomial(n, p_f)` failures and `k_n` the largest certifying count,
`P(certify) = P(X <= k_n) = I_(1-p_f)(n - k_n, k_n + 1)`. Normal rule:
`k_n = max{k <= n : k/n + c(n, alpha, beta) <= alpha}`. Clopper-Pearson
rule: `k_n = max{k : P(Binomial(n, alpha) <= k) <= beta}`, which gives
`P(certify) <= beta` for every `p_f >= alpha` and every `n`.

- Domain: integer `n >= 1`, `0 <= p_f <= 1`, `0 < alpha, beta < 1`;
  `k_n = -1` (probability zero) when no count certifies.
- Meaning: the decision depends on the failure count only through a
  threshold, so its probability is a binomial distribution function,
  evaluated through the regularized incomplete beta function for `n` up to
  `1e10`; `P(certify)` is not monotone in `n` because `k_n` is an integer.
- Code: `reliability.certification_probability`,

  `reliability.certification._certifies`,

### EQ-REL-CERT-003 — Moving-particles certification under a Poisson count

`M ~ Poisson(-N ln p_f)`, `p_hat = (1 - 1/N)^M`; certify when the

`M >= m* = min{m : P(Poisson(-N ln alpha) >= m) <= beta}`, so

- Meaning: the move count of the particle method is Poisson with mean
  growing like `-ln p_f` instead of `1/p_f`, so far fewer model calls give
  the same certification probability as crude Monte Carlo for small `p_f`;
  the false-certification probability stays at most `beta` for

### EQ-REL-AL-EFF-001 — Expected feasibility function

- Domain: `sigma > 0` (`EFF = 0` for `sigma = 0`); in the units of `G`, so
  the threshold assumes `G` of order one.
- Meaning: expected amount by which the prediction falls inside the band
  `|G| <= 2 sigma` around the limit state.

  `reliability.ak_mcs`.

### EQ-REL-AL-H-001 — Information-entropy learning function

With `D_+ = (2 sigma - mu) / sigma` and `D_- = (-2 sigma - mu) / sigma`:
`H = |(ln(sqrt(2 pi) sigma) + 1/2) [Phi(D_+) - Phi(D_-)] -
[(D_+ / 2) phi(D_+) - (D_- / 2) phi(D_-)]|`, the absolute value of

### EQ-REL-HLRF-001 — Hasofer-Lind-Rackwitz-Fiessler recursion

`u_hlrf = [(grad G(u_k) . u_k - G(u_k)) / ||grad G(u_k)||^2] grad G(u_k)`,
`d_k = u_hlrf - u_k`, `u_{k+1} = u_k + lambda_k d_k`.
Convergence: `|G(u)| <= eps |G(u_0)|` and
`||u - (alpha . u) alpha|| <= eps max(1, ||u||)`.

- Domain: `G` continuously differentiable near the iterates with non-zero
  gradient; plain HL-RF uses `lambda_k = 1`. Gradients are central differences
  [EQ-OPT-FD-001] unless an analytic gradient is supplied.
- Meaning: each step jumps to the design point of the limit state linearized at
  `u_k`; at a fixed point `u` is parallel to the gradient and on `G = 0`, the
  first-order optimality conditions of `min ||u|| s.t. G(u) = 0`.
- Code: `reliability.form_hlrf`.
- Source: [REF-HASOFER-LIND-1974], [REF-RACKWITZ-FIESSLER-1978].

### EQ-REL-HLRF-002 — iHL-RF merit function and Armijo step

`m(u) = ||u||^2 / 2 + c |G(u)|` with
`c = 2 max(||u_k||, ||u_hlrf||) / ||grad G(u_k)||`; `lambda_k` is the largest
`2^-j` with `m(u_k + lambda d_k) <= m(u_k) + 10^-4 lambda (u_k . d_k - c |G(u_k)|)`.

- Domain: as [EQ-REL-HLRF-001]. Because `grad G . d_k = -G(u_k)`, the

- Meaning: the HL-RF direction becomes a descent direction of a merit function,

  limit states. After 30 halvings the smallest trial step is accepted.

### EQ-REL-FORM-002 — General FORM index, probability, and importance

### EQ-REL-SORM-001 — Principal curvatures at the design point

Let `R` be orthonormal with last row `alpha` and `T` its first `n-1` rows.
The principal curvatures are the eigenvalues of
`A = T H T' / ||grad G(u*)||`, where `H` is the Hessian of `G` at `u*`.

- Domain: `G` twice differentiable at `u*` with non-zero gradient; `H` is a
  central-difference Hessian [EQ-OPT-FD-002] (`2n^2 + 1` model calls) and the
  eigenvalues come from cyclic Jacobi [EQ-LINALG-005].
- Meaning: near `u*` the limit surface is the paraboloid
  `v_n = beta + (1/2) sum_i kappa_i v_i^2` in rotated coordinates; positive
  `kappa_i` bend it away from the origin and shrink the failure domain.
- Code: `reliability.principal_curvatures`, `reliability.sorm`.
- Source: [REF-BREITUNG-1984], [REF-DERKIUREGHIAN-2005].

### EQ-REL-MP-001 — Moving-particles (last-particle) estimator

`p_hat=(1-1/N)^M`. Under exact conditional sampling `M ~ Poisson(-N ln p)`,
so `E[p_hat]=p`, `Var(p_hat)=p^2(p^{-1/N}-1)` and
`c.o.v. = sqrt(p^{-1/N}-1) ~ sqrt(-ln(p)/N)`.

- Domain: `N >= 2`, a continuous distribution of `G(U)` (no atoms), and
  exact sampling from the standard normal law restricted to `G < L` at each
  level `L`.
- Meaning: the levels `-ln P(G<=L_k)` form a Poisson process of intensity
  `N`; the scheme is the limit of ideal splitting in which each level
  discards a single particle, at an expected cost of `N(1 - Q ln p)`
  evaluations with `Q` Markov steps per move.

### EQ-REL-ISDP-001 — Importance sampling centered at the design point

Proposal `h(u) = phi_n(u - c)` with `c = u*` (or a supplied center);
`w(u) = phi_n(u) / h(u) = exp(||c||^2 / 2 - u . c)` and
`P_f ~= N^-1 sum_i I(G(u_i) <= 0) w(u_i)`. For a system proposal, the equal
mixture `h(u) = m^-1 sum_k phi_n(u - c_k)` over component design points gives
`w(u) = phi_n(u) / h(u)`.

- Domain: the proposal covers the failure contribution (always true for a
  Gaussian proposal); efficiency requires the failure mass to concentrate near
  the centers. Distant secondary failure regions are under-sampled and inflate
  the variance.
- Meaning: the specialization of [EQ-REL-IS-001] that reuses FORM to turn a
  rare event into a frequent one under the proposal.
- Code: `reliability.design_point_importance_sampling`,

### EQ-REL-SUBSET-001 — Subset-simulation product of conditional levels

`F_1 ⊃ F_2 ⊃ ... ⊃ F_m = F` with `F_j = {G(u) <= b_j}` and
`P_f = P(F_1) prod_{j=2}^{m} P(F_j | F_{j-1}) ~= p0^(m-1) N_F / N`. The
threshold `b_j` is the midpoint of the `N p0`-th and `(N p0 + 1)`-th smallest
values of `G` at the current level; the run stops when at least `N p0`
samples satisfy `G <= 0`.

- Domain: `N p0` a positive integer dividing `N`; a continuous response near
  the intermediate thresholds (level-0 ties are rejected).
- Meaning: a rare probability becomes a product of frequent conditional
  probabilities, each estimated from about `N` samples.
- Code: `reliability.subset_simulation`.
- Source: [REF-AU-BECK-2001].
  - [REF-AU-BECK-2001](../references.md#ref-au-beck-2001): Siu-Kui Au and James L. Beck. "Estimation of Small Failure Probabilities in High Dimensions by Subset Simulation." *Probabilistic Engineering Mechanics* 16(4), 263-277, 2001.

### EQ-REL-SUBSET-002 — Component-wise modified Metropolis step

For each coordinate, `xi_k = u_k + s Z` with `Z ~ N(0, 1)` is accepted with
probability `min(1, phi(xi_k) / phi(u_k))`; the candidate vector replaces the
current state only if `G(xi) <= b_j`, otherwise the chain repeats its state.

- Domain: independent standard-normal target restricted to `F_j`; the
  proposal spread `s > 0` controls acceptance and correlation.
- Meaning: generates conditional samples given `F_j` whose stationary law is
  `phi_n(u) I(u in F_j) / P(F_j)`, with acceptance rates that do not collapse
  in high dimension as a full-vector Metropolis step would.
- Code: `reliability.subset_simulation`.
- Source: [REF-AU-BECK-2001].
  - [REF-AU-BECK-2001](../references.md#ref-au-beck-2001): Siu-Kui Au and James L. Beck. "Estimation of Small Failure Probabilities in High Dimensions by Subset Simulation." *Probabilistic Engineering Mechanics* 16(4), 263-277, 2001.

### EQ-REL-SUBSET-003 — Subset-simulation coefficient of variation

`delta_j^2 = (1 - P_j) / (N P_j) (1 + gamma_j)`,
`gamma_j = 2 sum_{k=1}^{N_s - 1} (1 - k/N_s) rho_j(k)`,
`rho_j(k) = R_j(k)/R_j(0)` with
`R_j(k) = (N - k N_c)^-1 sum_chains sum_l I_l I_{l+k} - P_j^2`;
reported `delta ~= sqrt(sum_j delta_j^2)` and upper value `sum_j delta_j`.

- Domain: chains of length `N_s = 1/p0` started from `N_c = N p0` seeds;
  level 0 has `gamma = 0`. The root-sum-square value assumes uncorrelated
  level estimators and typically understates the true c.o.v.; the sum is the
  fully correlated value.
- Meaning: an approximate a-posteriori error measure that accounts for
  within-chain correlation of the indicator samples.
- Code: `reliability.subset_simulation` (`_level_cov`).
- Source: [REF-AU-BECK-2001].
  - [REF-AU-BECK-2001](../references.md#ref-au-beck-2001): Siu-Kui Au and James L. Beck. "Estimation of Small Failure Probabilities in High Dimensions by Subset Simulation." *Probabilistic Engineering Mechanics* 16(4), 263-277, 2001.

### EQ-REL-SUBSET-004 — Conditional-sampling step for subset simulation

`v_i = rho_i u_i + sigma_i z_i` with `z_i ~ N(0, 1)` and
`rho_i = sqrt(1 - sigma_i^2)`; the state moves to `v` if `G(v) <= b_j` and
repeats otherwise. Plain conditional sampling uses one fixed `rho` for every
coordinate (default `0.8`).

- Domain: independent standard-normal coordinates, `0 <= rho_i < 1`
  (`0 < sigma_i <= 1`), current state in `F_j = {G <= b_j}`.
- Meaning: the proposal is reversible with respect to the standard normal
  law, so no density ratio is needed and the stationary law is
  `phi_n(u) I(u in F_j) / P(F_j)`; unlike a random walk, the acceptance rate
  does not decay with the dimension.
- Code: `reliability.subset_simulation` (`sampler="cs"` and `"acs"`).

### EQ-REL-SUBSET-005 — Adaptive conditional sampling (aCS)

The `N_s = N p0` seeds are randomly permuted and each starts a chain of
`floor(N / N_s)` states (the remainder goes to the first chains).
`sigma_i = min(lambda sigma_0i, 1)`, `rho_i = sqrt(1 - sigma_i^2)`, with
`sigma_0i = 1` or the sample standard deviation of coordinate `i` over the
seeds. After every `N_a = ceil(100 N_s / N)` chains,
`a_hat = N_a^-1 sum min(1, a_c)` over their acceptance rates `a_c` and
`ln lambda <- ln lambda + (a_hat - a*) / sqrt(i + 1)`, `i = 0, 1, ...`
counting the updates of the level; `a* = 0.44`, `lambda = 0.6` at the first
conditional level and carried over to the next level.

- Domain: `lambda > 0`, `0 < a* < 1`, `N_a >= 1`.
- Meaning: a Robbins-Monro type adaptation of the conditional-sampling
  spread toward the acceptance rate that balances step length and
  rejections; a decreasing gain keeps the kernel nearly fixed late in a
  level.
- Code: `reliability.subset_simulation` (`sampler="acs"`).

### EQ-REL-SUBSET-006 — Level c.o.v. with chains of unequal length

### EQ-REL-HMCSS-001 — Rejection-sampling Hamiltonian step in standard space

With potential `U(u) = ||u||^2 / 2 - ln I(u in F_j)` and a unit mass
matrix, the Gaussian part of the Hamiltonian flow is exact:
`u(t) = p sin t + u_0 cos t`, `p ~ N(0, I)` drawn afresh for every step;
the end point `u(t_f)` is accepted if `G(u(t_f)) <= b_j` and the chain
repeats `u_0` otherwise.

- Domain: `0 < t_f <= pi/2`, current state in `F_j`; full momentum refresh
  (no partial refreshment).
- Meaning: the flow preserves the standard normal law, so rejecting end
  points outside `F_j` leaves the conditional law invariant without a
  gradient; the step equals conditional sampling with `rho = cos t_f`.

### EQ-REL-HMCSS-002 — Trajectory-time adaptation for RS-HMC

`t_f` starts at `pi/4`. After every `N_a` chains with mean acceptance `a`:
if `a < 0.3`, `t_f <- arcsin(sin t_f exp((a - 0.3)/2))`; if `a > 0.5`,
`t_f <- arcsin(min(1, sin t_f exp((a - 0.5)/2)))`; otherwise `t_f` is kept.

- Domain: `0 < t_f <= pi/2`, `N_a >= 1`; the adapted value is carried to
  the next level.
- Meaning: shortens the trajectory when too many end points leave `F_j` and
  lengthens it when nearly all stay inside, holding the acceptance rate in
  the band `[0.3, 0.5]`.
- Code: `reliability.subset_simulation` (`sampler="hmc"`).

### EQ-REL-SPLIT-001 — Relative variance of ideal splitting with equal levels

### EQ-REL-SPLIT-002 — Optimal number of splitting levels

so `M* ~ -ln(p)/x* = -0.6275 ln p`, `P_m=exp(-x*)=0.2032` and

  terms of order `1/N` dropped.
- Meaning: the optimal conditional probability per level does not depend on
  `p` or `N`; in practice `p` is unknown, so the thresholds cannot be set in
  advance and adaptive levels (subset simulation with `p_0 = 0.1` or
  `0.2`, moving particles) approximate the optimum.
- Code: `reliability.optimal_splitting`, `reliability.OPTIMAL_LEVEL_EXPONENT`.

### EQ-REL-SYS-001 — Series and parallel system failure events

or by the mixture importance sampler of [EQ-REL-ISDP-001].

- Domain: all components share one joint input law; each distinct model is
  evaluated once per sample.
- Meaning: the system event is a deterministic Boolean combination of
  component events on the same random input.

### EQ-REL-SYS-003 — Ditlevsen bi-modal series-system bounds
