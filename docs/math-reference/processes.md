## `probstat.processes.continuous`

### EQ-PROC-POIS-001 — Poisson counting process

`N(t) ~ Poisson(lambda t)`: `Pr(N(t) = k) = e^(-lambda t) (lambda t)^k / k!`;
`E[N(t)] = Var[N(t)] = lambda t`; increments over disjoint intervals are
independent.

- Domain: rate `lambda > 0`, `t >= 0`.
- Meaning: events that occur singly, independently, and at a constant
  average rate; equal mean and variance is its signature.
- Code: `processes.PoissonProcess.mean_count`,
  `processes.PoissonProcess.variance_count`, `processes.PoissonProcess.count_pmf`.
- Source: [REF-NORRIS-1997, Section 2.4].

### EQ-PROC-BM-001 — Brownian motion with drift

### EQ-PROC-CTMC-001 — Generator and Kolmogorov forward equation

`q_ij >= 0 (i != j)`, `q_ii = -sum_(j != i) q_ij`; `pi'(t) = pi(t) Q`, so
`pi(t) = pi(0) exp(Q t)`.

- Domain: finite state space; finite non-negative rates; rows of `Q` sum to
  zero (validated to `1e-10` times the row's total rate, then the diagonal is
  recomputed exactly as minus the row sum).
- Meaning: exponential holding time in `i` with rate `-q_ii`, then a jump to
  `j` with probability `q_ij / (-q_ii)`.
- Code: `processes.ContinuousTimeMarkovChain`.

### EQ-PROC-CTMC-002 — Uniformization

`q >= max_i |q_ii|`, `P = I + Q / q`;
`pi(t) = sum_(k >= 0) exp(-q t) (q t)^k / k! * pi(0) P^k`.

- Domain: `t >= 0`; `q t` finite. Every term is non-negative.
- Meaning: the CTMC is a discrete chain `P` observed at the jumps of a

### EQ-PROC-CTMC-003 — Poisson window and certified truncation bound

For `N ~ Poisson(lambda)`, `lambda = q t`:
`Pr(N >= k) <= exp(-lambda) (e lambda / k)^k` for `k >= lambda` and
`Pr(N <= k) <= exp(-lambda) (e lambda / k)^k` for `k <= lambda`, evaluated as
`log b(k) = (k - lambda) - k log1p((k - lambda) / lambda)`. Keep `[L, R]` with
both tails `<= tol / 4`; weights `w_m = 1`, `w_(k+1) = w_k lambda / (k + 1)`,
`w_(k-1) = w_k k / lambda` (mode `m`), normalized to sum one. L1 truncation
error `<= 2 Pr(N outside [L, R]) <= tol`. Rounding bound (componentwise
relative, first order): `u [m_prod (n + 3) + 2 span + (R - L) + 4]`,
`u = 2^-53`.

- Domain: `lambda > 0`; `tol` in `[1e-250, 0.5]`.
- Meaning: rigorous truncation of the uniformization series without
  underflow of `exp(-lambda)` for large `q t`.
- Code: `processes.ContinuousTimeMarkovChain.transient`,
  `processes.TransientSolution`.
- Source: [REF-FOX-GLYNN-1988] (mode-centred weights) and
  [REF-BOUCHERON-LUGOSI-MASSART-2013, Section 2.2] (Cramer-Chernoff bound).
  - [REF-FOX-GLYNN-1988](../references.md#ref-fox-glynn-1988): Bennett L. Fox and Peter W. Glynn. "Computing Poisson Probabilities." *Communications of the ACM* 31(4), 440-445, 1988.

### EQ-PROC-CTMC-004 — Accumulated reward and occupancy

`L(t) = int_0^t pi(s) ds = (1/q) sum_(k >= 0) Pr(N > k) pi(0) P^k`;

- Meaning: expected time per state, mission cost, downtime and expected

### EQ-PROC-CTMC-005 — Stationary law by GTH state reduction

`pi Q = 0`, `sum pi = 1`. For `k = n-1, ..., 1`:
`s_k = sum_(j < k) a_kj`; `a_ik <- a_ik / s_k`; `a_ij <- a_ij + a_ik a_kj`
(`i, j < k`, `i != j`); then `pi_0 = 1`, `pi_j = sum_(i < j) pi_i a_ij`,

- Domain: an irreducible closed class (applied to the unique closed class;
  transient states get zero mass).
- Meaning: subtraction-free Gaussian elimination; small componentwise
  relative error even for stiff rates.
- Code: `processes.ContinuousTimeMarkovChain.steady_state`,

### EQ-PROC-CTMC-006 — Absorption: fundamental matrix of a CTMC

`N = (-Q_TT)^-1`, `B = N Q_TA`, `m = N 1`. Solved by eliminating state `k`
with pivot `s_k = sum_(j < k) r_kj + d_k` (off-diagonal rates `r`, exit rate
`d`), updates `r_ij += r_ik r_kj / s_k`, `d_i += r_ik d_k / s_k`,
`b_i += r_ik b_k / s_k`, then back substitution.

- Domain: every closed class is a single absorbing state, so absorption is
  certain from every transient state.
- Meaning: `N_ij` expected time in `j` from `i`; `B_ik` absorption
  probability; `m_i` mean time to absorption (an MTTF when the absorbing
  states are failures).
- Code: `processes.ContinuousTimeMarkovChain.absorption`,
  `processes.CTMCAbsorption`.

### EQ-PROC-CTMC-008 — Scaling and squaring of the uniformized transition matrix

`tau = t / 2^s`; `E = exp(Q tau)`, `M = int_0^tau exp(Q u) du` row by row by
uniformization; `s` times `M <- M + E M`, `E <- E E`. Row-L1 truncation
bounds `d_E <- 2 d_E + d_E^2`, `d_M <- 2 d_M + d_E tau_k + d_E d_M`;
relative rounding `rho_E <- 2 rho_E + rho_E^2 + n u`,
`rho_M <- rho_E + rho_M + (n + 1) u`.

- Domain: `s >= 1`; chosen when cheaper than the direct series (large `q t`,
  few states).
- Meaning: all factors are non-negative, so no cancellation occurs; rows of
  `E` are rescaled to sum one (exact in real arithmetic, because the
  truncated rows built from normalized Poisson weights are exactly
  stochastic).
- Code: `processes.ContinuousTimeMarkovChain.transient` (`method="squaring"`),
  `.expected_time_in_states`.
- Source: [REF-MOLER-VAN-LOAN-2003] and [REF-REIBMAN-TRIVEDI-1988].
  - [REF-MOLER-VAN-LOAN-2003](../references.md#ref-moler-van-loan-2003): Cleve Moler and Charles Van Loan. "Nineteen Dubious Ways to Compute the Exponential of a Matrix, Twenty-Five Years Later." *SIAM Review* 45(1), 3-49, 2003.

### EQ-PROC-MC-001 — Finite Markov chain and transition matrix

`Pr(X_(t+1) = j | X_t = i, X_(t-1), ..., X_0) = P_ij`, with `P_ij >= 0` and
`sum_j P_ij = 1` for every row `i`.

- Domain: finite state space `{0..n-1}`; time-homogeneous transitions; rows
  checked to sum to one within `1e-10`.
- Meaning: the next state depends on the past only through the present
  state; a path is simulated by drawing each next state from row `X_t`.
- Code: `processes.MarkovChain`, `processes.MarkovChain.simulate`.
- Source: [REF-NORRIS-1997, Section 1.1].

### EQ-PROC-MC-002 — Chapman-Kolmogorov and n-step distributions

### EQ-PROC-MC-003 — Stationary distribution

`pi = pi P`, `pi_i >= 0`, `sum_i pi_i = 1`; solved as `(P' - I) pi = 0` with
one balance equation replaced by the normalization.

- Domain: unique exactly when the chain has a single closed communicating
  class; transient states then get `pi_i = 0`.
- Meaning: the law left invariant by one step; for an irreducible aperiodic
  chain it is also the limit of `pi_0 P^n` and the long-run fraction of time
  spent in each state.
- Code: `processes.MarkovChain.stationary_distribution`.
- Source: [REF-NORRIS-1997, Sections 1.7-1.8].

### EQ-PROC-MC-004 — Class structure and period

`i <-> j` iff `(P^m)_ij > 0` and `(P^n)_ji > 0` for some `m, n >= 0`; a class
`C` is closed iff `P_ij = 0` for `i in C`, `j not in C`;
`d(i) = gcd{n >= 1 : (P^n)_ii > 0}`, computed as the gcd of
`level(u) + 1 - level(v)` over class edges `u -> v` from breadth-first levels.

- Domain: finite chains; in a finite chain the closed classes are exactly the
  recurrent classes. The period is a class property; `0` marks a state that
  cannot return to itself.
- Meaning: irreducibility (one class) and aperiodicity (`d = 1`) decide
  whether the stationary law is unique and whether `pi_0 P^n` converges.
- Code: `processes.MarkovChain.communicating_classes`,
  `processes.MarkovChain.closed_classes`, `processes.MarkovChain.period`.
- Source: [REF-NORRIS-1997, Sections 1.2, 1.5, and 1.8].
  - [REF-NORRIS-1997](../references.md#ref-norris-1997): J. R. Norris. *Markov Chains*. Cambridge Series in Statistical and Probabilistic Mathematics. Cambridge University Press, 1997.

### EQ-PROC-MC-005 — Fundamental matrix of an absorbing chain

Canonical form `P = [[Q, R], [0, I]]` (transient block `Q`); `N = (I - Q)^-1`,
`B = N R`, `t = N 1`.

- Domain: at least one absorbing state, every closed class a single absorbing
  state, and at least one transient state (so `I - Q` is non-singular).
- Meaning: `N_ij` is the expected number of visits to transient `j` from

### EQ-PROC-SDE-001 — Euler-Maruyama scheme

`X_(n+1) = X_n + a(t_n, X_n) h + b(t_n, X_n) dW_n`, `dW_n ~ N(0, h)`.

### EQ-PROC-SDE-003 — Strong and weak errors

### EQ-PROC-SMP-001 — Semi-Markov kernel and mean sojourn times

`Q_ij(t) = P(J_(n+1) = j, X_(n+1) <= t | J_n = i) = p_ij F_ij(t)`, with the
embedded jump matrix `P = [p_ij]` and sojourn laws `F_ij` on `(0, inf)`;
`H_i(t) = sum_j Q_ij(t)` is the sojourn-time CDF of state `i` and
`tau_i = sum_j p_ij E[T_ij]` its mean. Exponential sojourns
`F_ij = Exp(q_i)` with `p_ij = q_ij / q_i` give the CTMC with generator `Q`.

- Domain: finite state space; rows of `P` sum to one for non-absorbing
  states; `F_ij(0) = 0`; finite positive means.
- Meaning: the next state is chosen by the jump chain, the holding time may
  depend on both the current and the next state and follow any law.
- Code: `processes.SemiMarkovProcess`, `processes.SemiMarkovProcess.kernel`,
  `processes.SemiMarkovProcess.from_ctmc`,
  `processes.SemiMarkovProcess.mean_sojourn_times`.

### EQ-PROC-SMP-002 — Markov renewal equation for interval transition probabilities and rewards

### EQ-PROC-SMP-003 — Trapezoidal discretisation and Richardson extrapolation

On `t_n = n h` with exact kernel increments `A_l = (Q(t_l) - Q(t_(l-1)))/2`
and `B_l = A_l + A_(l+1)`:
`(I - A_1) u_n = (1 - H(t_n)) r + A_n u_0 + sum_(l=1)^(n-1) B_l u_(n-l)`,
which is the trapezoidal rule `int_(t_(l-1))^(t_l) u(t_n - s) dQ(s) ~
(u_(n-l) + u_(n-l+1)) A_l`. With `u^(N)` and `u^(2N)` the solutions on `N`
and `2N` steps, the reported value is `(4 u^(2N) - u^(N)) / 3` and the error
estimate is `|u^(2N) - u^(N)| / 3`.

- Domain: second-order accuracy and the `h^2` error expansion behind the
  extrapolation require smooth kernel densities; increments use `sf` when
  `F > 1/2` to avoid cancellation.
- Meaning: an implicit, positivity-friendly scheme of cost `O(N^2)` per
  reward column. The error estimate measures the finer trapezoidal
  solution, so it is conservative for the extrapolated value when the
  expansion holds; it is not a rigorous bound.
- Code: `processes.SemiMarkovProcess` (`_grid_solution`, `_extrapolated`),
  `processes.SemiMarkovEstimate`, `processes.RenewalCurve`.
- Source: [REF-CORRADI-JANSSEN-MANCA-2004], [REF-LINZ-1985, Chapters 7-8].

### EQ-PROC-SMP-004 — Absorption and mean time to absorption

first-passage time to a set `S` is `m` of the process with `S` absorbing,

- Meaning: each visit to `j` lasts `tau_j` on average and visits and
  sojourns enter linearly, so only the sojourn means matter; for

### EQ-PROC-SMP-006 — Simulation of a semi-Markov path
