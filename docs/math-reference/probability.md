### EQ-PROB-002 — Probability of an event in a finite weighted space

`P(A) = sum_{omega in A} p(omega)`, where `p(omega) >= 0` and

## `probstat.probability.limit_theorems`

### EQ-LIM-001 — Berry-Esseen bound with Shevtsova's constant

`sup_z |P(Z_n <= z) - Phi(z)| <= C rho / (sigma^3 sqrt(n))`, with
`Z_n = sqrt(n) (Xbar_n - mu)/sigma`, `rho = E|X - mu|^3` and
`C = 0.4748`.

- Domain: i.i.d. summands with `sigma > 0` and `rho < inf`; `n >= 1`.
- Meaning: a uniform, non-asymptotic bound on the CLT error. The value is
  not capped at one, so for small `n` or very skewed summands it can be
  vacuous.
- Code: `probability.berry_esseen_bound`, `probability.clt_error_profile`.
- Source: [REF-SHEVTSOVA-2011].
  - [REF-SHEVTSOVA-2011](../references.md#ref-shevtsova-2011): Irina Shevtsova. "On the absolute constants in the Berry-Esseen type inequalities for identically distributed summands." arXiv preprint arXiv:1111.6554 [math.PR], 2011. The abstract states the bound `C_0 < 0.4748` on the classical i.i.d. Berry-Esseen constant. [https://arxiv.org/abs/1111.6554](https://arxiv.org/abs/1111.6554).
- Registry: [EQ-LIM-001](../equation-registry.md#eq-lim-001--berry-esseen-bound-with-shevtsovas-constant)

### EQ-LIM-002 — Exact laws of the standardized mean

Bernoulli: `P(Z_n <= z) = P(S <= floor(n p + z sqrt(n p q)))`,
`S ~ Binomial(n, p)`. Exponential(`lambda`): `P(Z_n <= z) = P(n, n + z
sqrt(n))` (regularized lower incomplete gamma, rate-free). Normal:
`P(Z_n <= z) = Phi(z)`. Tails of `Xbar_n - mu` follow from the same laws:
`Q(n, n (1 + lambda t))` and `P(n, n (1 - lambda t))` for the exponential.

- Domain: `0 < p < 1`, `lambda > 0`, `sigma > 0`, `n >= 1`.
- Meaning: closed forms that make CLT errors and tail probabilities exact
  rather than simulated.
- Code: `probability.standardized_mean_cdf`,
  `probability.sample_mean_upper_tail`,
  `probability.sample_mean_two_sided_tail`,
  `probability.limit_theorems.standard_normal_cdf`. Binomial masses use Loader's
  saddle-point form [REF-LOADER-2000], accurate to rounding for any `n`.
- Source: [REF-CASELLA-BERGER-2002], [REF-NIST-DLMF-GAMMA],
  [REF-LOADER-2000].
  - [REF-CASELLA-BERGER-2002](../references.md#ref-casella-berger-2002): George Casella and Roger L. Berger. *Statistical Inference*. 2nd edition. Duxbury, 2002.
  - [REF-NIST-DLMF-GAMMA](../references.md#ref-nist-dlmf-gamma): NIST Digital Library of Mathematical Functions, Chapters 5 and 8, "Gamma Function" and "Incomplete Gamma and Related Functions." National Institute of Standards and Technology. [https://dlmf.nist.gov/8](https://dlmf.nist.gov/8).
  - [REF-LOADER-2000](../references.md#ref-loader-2000): Catherine Loader. "Fast and Accurate Computation of Binomial Probabilities." Technical report, Lucent Technologies (Bell Laboratories), Murray Hill, NJ, 2000; revised version dated 5 February 2002. Saddle-point form of the binomial mass function with the Stirling error `delta(n)` (Equation 4) and the deviance `D_0` (Equation 6); the basis of R's `dbinom`. [https://www.r-project.org/doc/reports/CLoader-dbinom-2002.pdf](https://www.r-project.org/doc/reports/CLoader-dbinom-2002.pdf).

### EQ-LIM-003 — Kolmogorov distance to the normal law

`K_n = sup_z |F_n(z) - A_n(z)|`, with `A_n = Phi` or the Edgeworth `G_n`.
For a lattice `F_n` and monotone `Phi`, the supremum is attained at an
atom `z_k`, so `K_n = max_k max(|F_n(z_k^-) - Phi(z_k)|, |F_n(z_k) -
Phi(z_k)|)`.

- Domain: any `n >= 1`. For continuous `F_n` the supremum is located on a
  1601-node grid over `[max(-sqrt(n) - 8, -40), 10]` (plus the support edge
  when inside) and refined by golden-section search; both laws are compared
  at the standardized value of the rounded sum `n + z sqrt(n)`.
- Meaning: the exact uniform CLT error. The lattice formula is exact; the
  continuous maximization is numerical, and it agrees with a 40001-point
  scan to `1e-6` in the tests.
- Code: `probability.kolmogorov_distance_to_normal`.
- Source: [REF-CASELLA-BERGER-2002], [REF-BRENT-1973].
  - [REF-CASELLA-BERGER-2002](../references.md#ref-casella-berger-2002): George Casella and Roger L. Berger. *Statistical Inference*. 2nd edition. Duxbury, 2002.
  - [REF-BRENT-1973](../references.md#ref-brent-1973): Richard P. Brent. *Algorithms for Minimization without Derivatives*. Prentice-Hall, 1973.
- Registry: [EQ-LIM-003](../equation-registry.md#eq-lim-003--kolmogorov-distance-to-the-normal-law)

### EQ-LIM-004 — One-term Edgeworth expansion

`G_n(z) = Phi(z) - phi(z) gamma (z^2 - 1) / (6 sqrt(n))`, with
`gamma = E(X - mu)^3 / sigma^3`.

- Domain: non-lattice summands with a finite third moment. Lattice
  summands need an additional discontinuous correction, which is not
  implemented, so the code raises.
- Meaning: `F_n - G_n = o(n^-1/2)` uniformly. It also gives
  `sqrt(n) K_n -> |gamma| phi(0)/6`, which is `1/(3 sqrt(2 pi))` for
  exponential summands.
- Code: `probability.edgeworth_cdf`,
  `probability.kolmogorov_distance_to_normal`.
- Source: [REF-HALL-1992].
  - [REF-HALL-1992](../references.md#ref-hall-1992): Peter Hall. *The Bootstrap and Edgeworth Expansion*. Springer Series in Statistics. Springer-Verlag, New York, 1992. ISBN 0-387-97720-1.
- Registry: [EQ-LIM-004](../equation-registry.md#eq-lim-004--one-term-edgeworth-expansion)

### EQ-LIM-005 — Chebyshev bound for the sample mean

### EQ-LIM-006 — Hoeffding bound

`P(Xbar_n - mu >= t) <= exp(-2 n t^2 / (b - a)^2)` for independent
`X_i in [a, b]`. The two-sided bound doubles this.

- Domain: bounded support, `t > 0`.
- Meaning: exponential concentration that uses only the range.
- Code: `probability.hoeffding_bound`, `probability.compare_tail_bounds`.
- Source: [REF-HOEFFDING-1963], [REF-WASSERMAN-2004].

### EQ-LIM-007 — Bernstein bound

`P(Xbar_n - mu >= t) <= exp(-n t^2 / (2 (sigma^2 + c t / 3)))` for
independent summands with `|X_i - mu| <= c`. This is the bounded case of
the sub-gamma inequality with `v = n sigma^2`, scale `c/3`, deviation
`n t`.

- Domain: `|X - mu| <= c` almost surely, `t > 0`.
- Meaning: tighter than Hoeffding when `sigma^2` is small relative to the
  range.
- Code: `probability.bernstein_bound`, `probability.compare_tail_bounds`.
- Source: [REF-BOUCHERON-LUGOSI-MASSART-2013].
  - [REF-BOUCHERON-LUGOSI-MASSART-2013](../references.md#ref-boucheron-lugosi-massart-2013): Stéphane Boucheron, Gábor Lugosi, and Pascal Massart. *Concentration Inequalities: A Nonasymptotic Theory of Independence*. Oxford University Press, 2013.
- Registry: [EQ-LIM-007](../equation-registry.md#eq-lim-007--bernstein-bound)

### EQ-LIM-008 — Delta method and exact small-sample variances

Delta: `Var g(Xbar_n) ~ g'(mu)^2 sigma^2 / n`. Exact comparisons:

- normal `Xbar^2`: `4 mu^2 sigma^2/n + 2 sigma^4/n^2`;
- normal `exp(Xbar)`: `(e^{s^2} - 1) e^{2 mu + s^2}`, with
  `s^2 = sigma^2/n`;
- exponential `1/Xbar`: `(n lambda)^2 / ((n-1)^2 (n-2))`;
- Bernoulli `g(Xbar)`: a finite binomial sum.

- Domain: `g` differentiable at `mu`; `n >= 3` for `1/Xbar`.
- Meaning: the first-order approximation's relative error at small `n`.
  It fails completely when `g'(mu) = 0`.
- Code: `probability.delta_method_variance`,
  `probability.delta_method_normal_square`,
  `probability.delta_method_normal_exp`,
  `probability.delta_method_exponential_reciprocal`,
  `probability.delta_method_bernoulli`.
- Source: [REF-CASELLA-BERGER-2002].
  - [REF-CASELLA-BERGER-2002](../references.md#ref-casella-berger-2002): George Casella and Roger L. Berger. *Statistical Inference*. 2nd edition. Duxbury, 2002.
- Registry: [EQ-LIM-008](../equation-registry.md#eq-lim-008--delta-method-and-exact-small-sample-variances)

### EQ-LIM-010 — Third central moments of the summands

- Bernoulli: `E(X - p)^3 = p q (1 - 2p)` and `E|X - p|^3 = p q (p^2 +
  q^2)`.
- Exponential(`lambda`): `E(X - mu)^3 = 2/lambda^3` and
  `E|X - mu|^3 = (12/e - 2)/lambda^3`.
- Normal: `0` and `2 sqrt(2/pi) sigma^3`.

- Domain: the parameter domains of the families.
- Meaning: the inputs of the Berry-Esseen bound (`rho`) and of the
  Edgeworth term (skewness).
- Code: `probability.bernoulli_summand`, `probability.exponential_summand`,
  `probability.normal_summand`.

## `probstat.probability.measure`

### EQ-MEAS-001 — Generated sigma-algebra on a finite set

`sigma(G) = { union of atoms in S : S subset of atoms }`, where outcomes
`omega ~ omega'` share an atom iff `1_C(omega) = 1_C(omega')` for every
generator `C in G`; with `k` atoms, `|sigma(G)| = 2^k`. A family `F` is a
sigma-algebra iff `Omega in F`, `A in F => Omega \ A in F`, and
`A, B in F => A union B in F` (finite unions suffice on a finite set). `G` is
a sub-sigma-algebra of `F` iff every atom of `G` is a union of atoms of `F`.

- Domain: non-empty finite `Omega`; any finite collection `G` of subsets
  (empty `G` gives `{empty, Omega}`, no `G` gives the power set).
- Meaning: the events an observer can distinguish; atoms are the finest
  distinguishable outcomes.
- Code: `probability.FiniteMeasurableSpace`, `probability.is_sigma_algebra`,
  `FiniteMeasurableSpace.is_measurable`,
  `FiniteMeasurableSpace.is_sub_sigma_algebra_of`.
- Source: [REF-BILLINGSLEY-1995, Section 2], [REF-DURRETT-2019, Section 1.1].

### EQ-MEAS-002 — Measure from atom masses

`mu(A) = sum_(a atom, a subset of A) m(a)` with `m(a) >= 0`; `mu` is a
probability measure iff `mu(Omega) = 1`. The restriction to a
sub-sigma-algebra `G` assigns each `G`-atom the `mu`-measure of that atom.

- Domain: `A` measurable; masses exact fractions or finite floats.
- Meaning: non-negativity and countable additivity hold by construction;
  subsets that split an atom have no measure.
- Code: `probability.FiniteMeasure`, `FiniteMeasure.measure_of`,
  `FiniteMeasure.from_point_masses`, `FiniteMeasure.restrict`,
  `FiniteMeasure.counting`.

### EQ-MEAS-003 — Measurable maps and pushforward measures

`f : (Omega, F) -> (Omega', F')` is measurable iff `f^-1(B) in F` for every
atom `B` of `F'`; a finite-valued function into its power-set codomain is
measurable iff it is constant on every atom of `F`. The image measure is
`(mu o f^-1)(B) = mu(f^-1(B))`; `sigma(f)` has the level sets
`f^-1({y})` as atoms.

- Domain: finite codomain; values must be target outcomes.
- Meaning: the law of a random element is the pushforward of the
  underlying measure.
- Code: `probability.FiniteMeasurableSpace.is_measurable_map`,
  `FiniteMeasurableSpace.is_measurable_function`,
  `FiniteMeasurableSpace.generated_by_map`, `probability.FiniteMeasure.pushforward`.

### EQ-MEAS-004 — Lebesgue integral of simple and measurable functions

`integral (sum_i c_i 1_(A_i)) dmu = sum_i c_i mu(A_i)`; a measurable `f` on
a finite space is simple on the atom partition, so
`integral f dmu = sum_a f(a) mu(a)` and
`integral_A f dmu = integral f 1_A dmu`.

- Domain: measurable `A_i` (not necessarily disjoint) and measurable real
  `f`.
- Meaning: expectation is integration against the measure; it is the
  finite case of the Lebesgue integral.
- Code: `probability.FiniteMeasure.simple_integral`, `FiniteMeasure.integrate`,
  `FiniteMeasure.integrate_over`.
- Source: [REF-BILLINGSLEY-1995, Sections 15-16], [REF-DURRETT-2019,

### EQ-MEAS-005 — Product measure and Fubini-Tonelli

`(mu x nu)(a x b) = mu(a) nu(b)` on the atoms `a x b` of the product
sigma-algebra, and
`integral f d(mu x nu) = integral [integral f(x, y) nu(dy)] mu(dx)
= integral [integral f(x, y) mu(dx)] nu(dy)`.

- Domain: finite factors; `f` measurable for the product sigma-algebra
  (hence integrable).
- Meaning: independent coordinates and the interchange of the order of
  integration.
- Code: `probability.FiniteMeasurableSpace.product`, `probability.FiniteMeasure.product`,
  `FiniteMeasure.fubini_check`, `probability.FubiniCheck`.

### EQ-MEAS-006 — Absolute continuity and the Radon-Nikodym derivative

`nu << mu` iff `mu(a) = 0 => nu(a) = 0` for every atom; then
`(d nu / d mu)(a) = nu(a) / mu(a)` on `mu(a) > 0` (any value, here `0`, on
`mu`-null atoms) and `nu(A) = integral_A (d nu / d mu) dmu`. Conversely a
non-negative measurable `g` defines `nu(A) = integral_A g dmu`.

- Domain: both measures on the same finite measurable space.
- Meaning: densities, likelihood ratios, and change of measure; the
  derivative is unique only `mu`-almost everywhere.
- Code: `probability.FiniteMeasure.is_absolutely_continuous_wrt`,
  `FiniteMeasure.radon_nikodym_derivative`, `FiniteMeasure.with_density`.
- Source: [REF-BILLINGSLEY-1995, Sections 16 and 32].

- Registry: [EQ-MEAS-006](../equation-registry.md#eq-meas-006--absolute-continuity-and-the-radon-nikodym-derivative)

### EQ-MEAS-007 — Chain rule for Radon-Nikodym derivatives

If `lambda << nu << mu`, then `d lambda / d mu = (d lambda / d nu)
(d nu / d mu)` `mu`-almost everywhere.

- Domain: three measures on one finite measurable space.
- Meaning: likelihood ratios compose; importance weights for a two-step
  change of measure multiply.
- Code: verified with `probability.FiniteMeasure.radon_nikodym_derivative` in

### EQ-MEAS-008 — Conditional expectation given a sub-sigma-algebra

For a sub-sigma-algebra `G` with atom `A`, `mu(A) > 0`:
`E[X | G](omega) = integral_A X dmu / mu(A)` for `omega in A` (any value on
null atoms). It is `G`-measurable with `integral_B E[X | G] dmu =
integral_B X dmu` for all `B in G`; tower property
`E[E[X | G] | H] = E[X | H]` for `H subset G`; and
`E[Z X | G] = Z E[X | G]` for `G`-measurable `Z`.

- Domain: measurable real `X`, `Z`; `H subset G subset F`.
- Meaning: the best `G`-measurable prediction of `X`, unique almost
  everywhere.
- Code: `probability.FiniteMeasure.conditional_expectation`,
  `FiniteMeasure.verify_tower_property`,
  `FiniteMeasure.verify_taking_out_what_is_known`.
- Source: [REF-BILLINGSLEY-1995, Section 34], [REF-DURRETT-2019, Section 4.1].

### EQ-MEAS-009 — Total-variation distance on a finite space

### EQ-MEAS-010 — Completeness of a statistic on a finite family

With parameters `theta_1, ..., theta_m` and statistic values `t_1, ..., t_k`
charged by some `P_theta`, let `A[i, j] = P_(theta_i)(T = t_j)`. `T` is
complete iff `E_theta[g(T)] = sum_j A[i, j] g(t_j) = 0` for all `i` forces
`g = 0`, that is, iff `rank A = k`. A non-zero null vector of `A` is an
unbiased estimator of zero.

- Domain: finite sample space and finite parameter set; exact rank for
  fractions, tolerance-based rank with partial pivoting for floats.
- Meaning: for the binomial count with `n` trials completeness holds iff at
  least `n + 1` distinct `p` in `(0, 1)` are included; the full sample is
  never complete for `n >= 2`.
- Code: `probability.check_completeness`,
  `probability.is_complete_statistic`, `probability.CompletenessCheck`.
- Source: [REF-LEHMANN-CASELLA-1998, Section 1.6],
