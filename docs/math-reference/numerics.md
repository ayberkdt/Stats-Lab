### EQ-NUM-DD-001 — Error-free transformations and double-double arithmetic

`s = fl(a + b)`, `e = (a - (s - v)) + (b - v)` with `v = s - a` gives
`s + e = a + b` exactly (two-sum); with Veltkamp's splitting
`a = a_h + a_l` (`c = (2^27 + 1) a`, `a_h = c - (c - a)`), `p = fl(a b)`,
`e = ((a_h b_h - p) + a_h b_l + a_l b_h) + a_l b_l` gives `p + e = a b`
exactly (two-product). A double-double `x_h + x_l` (`|x_l| <= ulp(x_h)/2`)
is added, multiplied, and divided with these transformations, with relative
errors of a few `2^-104`; `exp(x_h + x_l) = exp(x_h) (1 + x_l)`.

- Domain: finite floats without overflow; the splitting needs
  `|a| <= 1e300`, and the products are exact unless partial products
  underflow (below `1e-290`).
- Meaning: carries about 106 bits through the exponent of a special-function
  prefactor or the argument of `erfc`, so that the outer function does not
  amplify a rounding of its argument.
- Code: `numerics._double_double.two_sum`,
  `numerics._double_double.two_product`, `numerics._double_double.dd_add`,
  `numerics._double_double.dd_mul`, `numerics._double_double.dd_div`,
  `numerics._double_double.dd_exp`,
  `distributions._continuous.standardized_double_double`.

### EQ-NUM-DD-002 — Table-driven double-double logarithm and Stirling remainder

`log x = k ln 2 + log(j/64) + 2 atanh(y)`, `x = m 2^k`, `m` in
`[sqrt(1/2), sqrt 2)`, `j = round(64 m)`, `y = (m - j/64)/(m + j/64)`
(`|y| < 0.0056`), `2 atanh y = 2y + 2y (y^2/3 + y^4/5 + y^6/7 + y^8/9)`;
`log(1 + t) - t = -t y + (2/3) y^3 + 2y sum_(k=2..10) y^(2k)/(2k+1)` with
`y = t/(2 + t)` for `|t| <= 1/16`, and `log(1 + t) - t` from the logarithm
otherwise; `sigma(a) = lgamma(a) - (a - 1/2) log a + a - log sqrt(2 pi)`
equals the Stirling series for `a >= 15` and, for smaller `a` with
`z = a + n >= 15`, `sigma(a) = (z - 1/2) log z - (a - 1/2) log a - n +
sigma(z) - log prod_(k<n) (a + k)`.

- Domain: positive finite arguments; `|t| <= 1/2` for the `log1pmx` form.
  The table values `log(j/64)` are computed once in 40-digit decimal
  arithmetic.
- Meaning: absolute errors below `1e-22` (logarithm), relative errors
  below `1e-20` (`log1pmx`), and absolute errors below `2e-18`
  (`sigma`), so that
  exponents of size several hundred are exact to far below one ulp.

### EQ-NUM-DD-003 — Complementary error function at a double-double argument

`erfc(w_h + w_l) = erfc(w_h) - (2/sqrt(pi)) exp(-w_h^2) w_l
+ O(w_h w_l^2 exp(-w_h^2))`.

- Domain: double-double `w`; the correction is skipped for `|w_h| > 27.5`,
  where `erfc` is 0 or 2 in floats.
- Meaning: a rounded argument `w_h` perturbs `erfc` by the relative amount
  `2 w^2 |w_l/w|`, which is up to `1400` ulp at `w = 26`; the first-order
  term removes it and leaves the error of `math.erfc` at an exact float
  argument (measured at most `2.04` ulp on 300 random arguments in
  `[0, 27]`, CPython 3.12 on Windows).
- Code: `numerics._double_double.erfc_double_double`.

### EQ-AD-DUAL-001 — Forward-mode dual-number chain rule

`f(a + b.eps) = f(a) + f'(a) b.eps` with `eps_i eps_j = 0`; for binary
operations `(a + b eps)(c + d eps) = ac + (bc + ad) eps` and
`(a + b eps)/(c + d eps) = a/c + (b - (a/c) d)/c eps`. Seeding `x_i + e_i eps`
gives `f(x) + grad f(x) . eps` from one evaluation (vector-tangent mode).

- Domain: functions composed of `+ - * / **` and elementary functions that
  are differentiable at the evaluation point; at kinks (`abs(0)`,
  `hypot(0, 0)`) the derivative is defined as 0.
- Meaning: exact (to rounding) gradients without a step size; one call of
  the user function per gradient.
- Code: `numerics.Dual`, `numerics.admath`, `numerics.value_and_gradient`,
  `numerics.gradient`, `numerics.jacobian`, `numerics.GradientEvaluator`.
- Source: [REF-GRIEWANK-WALTHER-2008, Chapter 3].

### EQ-AD-HESSIAN-001 — Forward-over-forward Hessian

Seed `x_i = (x_i + e_i eps1) + (e_i + 0 eps1) eps2`; then
`f = (f + grad f . eps1) + sum_j (d_j f + grad d_j f . eps1) eps2_j`, so the
eps1-tangent of the j-th eps2-tangent is column `j` of the Hessian. The
result is symmetrized, `(H + H')/2`.

- Domain: twice differentiable `f`; `trigamma` of a dual (third derivative
  of `lgamma`) is not available.
- Meaning: exact Hessian from one nested evaluation (cost `O(d^2)` per
  operation).
- Code: `numerics.hessian`, `numerics.value_gradient_and_hessian`,
  `inference.laplace_approximation`.
- Source: [REF-GRIEWANK-WALTHER-2008, Chapters 3 and 13].
  - [REF-GRIEWANK-WALTHER-2008](../references.md#ref-griewank-walther-2008): Andreas Griewank and Andrea Walther. *Evaluating Derivatives: Principles and Techniques of Algorithmic Differentiation*. 2nd edition. ## `probstat.numerics.de_transforms`

### EQ-NUM-DE-001 — Double-exponential rules on general ranges

`int f(x) dx = int f(phi(t)) phi'(t) dt ~ h sum_k f(phi(kh)) phi'(kh)` with
tanh-sinh `phi(t) = a + (b - a)/(1 + exp(-pi sinh t))` on `[a, b]`, exp-sinh
`phi(t) = a + exp((pi/2) sinh t)` on `[a, inf)`, and sinh-sinh
`phi(t) = sinh((pi/2) sinh t)` on the line; `h = 2^-k` is halved, reusing
nodes, until `E = max(|T_k - T_{k-1}|, 50 eps h sum |f phi'|) +
h sum' |f phi'| min(1, 2 alpha ulp(x)/d) + sum_sides |f phi'|(t_e) / r <=
max(abs_tol, rel_tol |T_k|)`, `d` being the distance to the nearest finite
end, `sum'` running over nodes with `ulp(x)/d >= 1e-4`, `alpha` the local
log-log slope of `|f|` against `d`, and `t_e` the outermost node on each side
with decay rate `r` of `|f phi'|` there.

- Domain: `f` analytic in a strip around the open range, integrable end
  singularities at a zero end, decay faster than `1/|x|` on infinite ranges.
- Meaning: the transformed integrand decays double-exponentially, so the
  trapezoidal error falls like `exp(-c N / log N)`; the rounding term guards
  against singularities at a non-zero end that floating point cannot resolve
  (it vanishes for integrands that are flat at the ulp scale, `alpha ~ 0`),
  and the truncation term against mass beyond the outermost nodes (slow
  algebraic decay such as `x^-1.025` at infinity or `x^-0.97` at zero).
- Code: `numerics.tanh_sinh_interval`, `numerics.exp_sinh`,
  `numerics.sinh_sinh`, `numerics.integrate`.
- Source: [REF-TAKAHASI-MORI-1974], [REF-MORI-SUGIHARA-2001].
  - [REF-TAKAHASI-MORI-1974](../references.md#ref-takahasi-mori-1974): Hidetosi Takahasi and Masatake Mori. "Double Exponential Formulas for Numerical Integration." *Publications of the Research Institute for Mathematical Sciences* 9(3), 721-741, 1974 (volume dated 1973/74). DOI: [10.2977/prims/1195192451](https://doi.org/10.2977/prims/1195192451).
  - [REF-MORI-SUGIHARA-2001](../references.md#ref-mori-sugihara-2001): Masatake Mori and Masaaki Sugihara. ### EQ-VAL-QUAD-DE-001 — Tanh-sinh quadrature on (0, 1)

`int_a^b g(u) du = (b - a) int w(t) g(a + (b - a) x(t)) dt`,
`x(t) = 1/(1 + exp(-pi sinh t))`, `w(t) = pi cosh(t) x (1 - x)`, trapezoidal
rule with `h = 2^-k`, nodes kept while `min(x, 1 - x) >= 1e-300`. The error
estimate is `|T_k - T_{k-1}|` plus the truncation term `|T(t_e)| / r` on each
side, with `T(t_e)` the weighted integrand at the outermost node and `r` its
decay rate towards the edge. Pieces split at breakpoints `(u, 1 - u)` (with
exact complements near one) are converged when `sum E_i <= max(tol |sum I_i|,
abs_tol)`.

- Domain: integrands smooth inside, integrable endpoint singularities.
- Meaning: double-exponential decay of the transformed integrand gives fast
  convergence for quantile-scale integrals.
- Code: `numerics.double_exponential.tanh_sinh` (re-exported as
  `numerics.tanh_sinh`; used by `validation.scoring`, `validation.shift`,
  and `information.wasserstein.quantile_wasserstein`).

## `probstat.numerics.gauss_kronrod`

### EQ-NUM-GK15-001 — Gauss-Kronrod G7-K15 panel and QUADPACK local error

On `[a, b]` with centre `c` and half-width `h`,
`K15 = h sum_{i=1}^{15} w_i f(c + h x_i)` and `G7 = h sum_{j=1}^{7} v_j f(c + h y_j)`,
the seven `y_j` being Gauss-Legendre nodes contained in the fifteen Kronrod
nodes `x_i`. With `I_abs = h sum w_i |f_i|` and
`I_asc = h sum w_i |f_i - K15/(2h)|`, the local error estimate is
`E = max(50 eps I_abs, I_asc min(1, (200 |K15 - G7| / I_asc)^1.5))`.

- Domain: finite panel; `f` finite at the 15 interior nodes (never at `a`, `b`).
- Meaning: K15 is exact for polynomials of degree at most 22 and G7 for degree
  at most 13; the scaled difference is QUADPACK's empirical, deliberately
  pessimistic error estimate.
- Code: `numerics.gauss_kronrod.kronrod_panel`, `numerics.gauss_kronrod`.

### EQ-NUM-QAG-001 — Globally adaptive bisection and the QAGI substitution

Keep a partition `{P_k}` with estimates `(I_k, E_k)` from [EQ-NUM-GK15-001];
bisect `argmax_k E_k` until `sum E_k <= max(abs_tol, rel_tol |sum I_k|)` or
the panel count reaches `limit`. Infinite ranges use
`int_a^inf f(x) dx = int_0^1 f(a + (1 - t)/t) t^-2 dt` (and the folded
`f(x) + f(-x)` on the whole line).

- Domain: `abs_tol >= 0`, `rel_tol >= 50 eps` when `abs_tol = 0`, `limit >= 1`.
- Meaning: refinement concentrates where the local error is largest; reaching
  `limit` or an unbisectable panel is reported as non-convergence.
- Code: `numerics.gauss_kronrod`, `numerics.integrate`.
- Source: [REF-PIESSENS-QUADPACK-1983].
  - [REF-PIESSENS-QUADPACK-1983](../references.md#ref-piessens-quadpack-1983): Robert Piessens, Elise de Doncker-Kapenga, Christoph W. Überhuber, and David K. ### EQ-NN-MLP-001 — Multilayer perceptron

`h_0 = x`, `h_l = sigma_l(W_l h_{l-1} + b_l)` for `l = 1, ..., L`, with
`sigma_L` the output activation (identity by default); the network output is
`h_L`. Parameters `(W_1, b_1, ..., W_L, b_L)` are stored as one flat vector.

- Domain: real inputs of the declared width; activations `tanh`, logistic
  sigmoid `(1 + tanh(z/2))/2`, softplus `max(z, 0) + log1p(exp(-|z|))`, or
  identity.
- Meaning: a smooth parametric function class; with reverse-mode
  differentiation of a scalar loss its gradient costs a small multiple of one
  evaluation.
- Code: `numerics.MLP`.

### EQ-NUM-PROFILE-001 — Performance ratio

`r_(p,s) = t_(p,s) / min{t_(p,u) : u in S}`, with `r_(p,s) = inf` when solver
`s` does not solve problem `p`.

- Domain: a set `S` of solvers and `P` of `n_p` problems; positive costs
  `t_(p,s)` (time, evaluations, or any performance measure).
- Meaning: how many times more expensive solver `s` is on problem `p` than
  the best solver on that problem. Sending the failure value `r_M` of the
  source to infinity changes no profile value for `tau < r_M`.
- Code: `numerics.performance_ratios`, `numerics.performance_profile`.

### EQ-NUM-PROFILE-002 — Performance profile

`rho_s(tau) = |{p in P : r_(p,s) <= tau}| / n_p`; `rho_s(1)` is the fraction
of wins (ties count for every tied solver) and
`rho_s* = lim_(tau -> inf) rho_s(tau)` the fraction of problems solved.

- Domain: ratios of [EQ-NUM-PROFILE-001]; `tau` real.
- Meaning: the distribution function of a solver's performance ratio; a
  nondecreasing, right-continuous step function. `tau_s(f)`, the smallest
  `tau` with `rho_s(tau) >= f`, is the ratio at which the solver solves a
  fraction `f` of the problems.
- Code: `numerics.PerformanceProfile.value`, `wins`, `solved_fraction`,
  `tau_at`, `breakpoints`; `visualization.profile_plots.plot_performance_profile`.

### EQ-NUM-REFERENCE-002 — Error function series and Laplace continued fraction

`erf x = (2/sqrt pi) exp(-x^2) sum_(n >= 0) 2^n x^(2n+1) / (1 3 ... (2n+1))`;
`sqrt(pi) exp(x^2) erfc x = x/(x^2 + (1/2)/(1 + 1/(x^2 + (3/2)/(1 + 2/(x^2 + ...)))))`;
`Phi(x) = erfc(-x/sqrt 2)/2`.

- Domain: real `x`; the fraction is used for `x >= max(3, sqrt(w)/2)` with `w`
  working digits, the series below.
- Meaning: the series has positive terms with ratio `2x^2/(2n+3)`, so once the
  ratio is at most `1/2` the tail is below the last term; the fraction has
  positive elements, so its convergents bracket the value and the difference
  of successive convergents bounds the truncation error. `erfc` of moderate
  arguments is `1 - erf` recomputed with the digits the cancellation removes;
  `Phi` carries `log10(1 + x^2)` extra digits for the rounding of `x/sqrt 2`.
- Code: `numerics.reference_erf`, `numerics.reference_erfc`,
  `numerics.reference_normal_cdf`.
- Source: [REF-NIST-DLMF, Equations 7.2.2, 7.6.2, and 7.9.1].

### EQ-NUM-REFERENCE-003 — Modified Lentz evaluation and complements

`f_j = f_(j-1) C_j D_j` with `D_j = 1/(b_j + a_j D_(j-1))`,
`C_j = b_j + a_j / C_(j-1)` (zero denominators replaced by a tiny number),
stopped when `|C_j D_j - 1| <= 10^-w`; a complement `1 - v` is accepted when
`-log10(1 - v)`, the number of digits lost to cancellation, is at most the
extra digits carried in `v`.

- Domain: continued fractions `b_0 + a_1/(b_1 + a_2/(b_2 + ...))` with
  `b_0 != 0`; values `v` with relative error `10^-w`.
- Meaning: forward evaluation of a continued fraction without choosing the
  depth in advance; the stopping test compares successive convergents. The
  complement rule turns a relative accuracy of `v` into one of `1 - v`.
- Code: `numerics.reference` (`_lentz`, `_complement`).

### EQ-NUM-REFERENCE-005 — Shifted Stirling series for log Gamma

  truncation error is known; near the zeros `x = 1, 2` the evaluation is
  repeated with `log10(|log Gamma(z)| / |log Gamma(x)|)` extra digits.
- Code: `numerics.reference_log_gamma`.

### EQ-AD-REVERSE-001 — Reverse-mode (adjoint) sweep

For an evaluation recorded as elementary operations `v_i = phi_i(v_j, j < i)`
with local partials `c_ij = d phi_i / d v_j`, seed `vbar_y = 1` (or
`vbar_(y_k) = w_k` for a vector function) and all other adjoints 0, then for
`i = N, N-1, ..., 1` set `vbar_j <- vbar_j + vbar_i c_ij` for every parent
`j` of node `i`. The input adjoints are `grad f(x)` (or `w' J(x)`).

- Domain: functions composed of `+ - * / **` and elementary functions that
  are differentiable at the evaluation point; unbounded derivatives

  origin) are rejected; at the kinks `abs(0)` and `hypot(0, ..., 0)` the
  derivative is defined as 0.
- Meaning: exact (to rounding) gradient from one recorded evaluation and
  one backward sweep; the operation count is a small multiple of that of
  `f`, independent of the number of inputs.
- Code: `numerics.ReverseVariable`, `numerics.reverse_value_and_gradient`,

### EQ-AD-FOR-001 — Forward-over-reverse Hessian and Hessian-vector product

Record the tape of EQ-AD-REVERSE-001 on the dual inputs `x_i + t_i eps`;
every value and partial is then a dual, and so is every adjoint. With
`t = e_1, ..., e_d` (vector tangent) the adjoint of input `i` is
`d f / d x_i + sum_j H_ij eps_j`, so its tangent is row `i` of the Hessian;
with a single tangent `t = v` its tangent is `(H v)_i`. The full Hessian is
symmetrized, `(H + H')/2`.

- Domain: twice differentiable `f`; the Hessian of `digamma` (a dual
  `trigamma`) is not available.
- Meaning: exact Hessian at about `d` times the cost of one gradient, and
  an exact Hessian-vector product at a small multiple of one gradient
  without forming `H`.
- Code: `numerics.reverse_hessian`,
  `numerics.reverse_value_gradient_and_hessian`,
  `numerics.hessian_vector_product`, `inference.laplace_approximation`.
